# バランス調整メモ

数値の置き場所と、その数値をなぜその値にしたかの記録。
**ロジックの中に数値を直書きしない。** 触るのは下記のファイルだけ。

| 調整したい対象 | ファイル |
|---|---|
| 練習の効果・体力消耗・カード出現率 | `src/core/card/cardDefs.ts` |
| マスの出現率・盤面の長さ | `src/core/board/boardDefs.ts` |
| 成長倍率（やる気・学年・体力・カンスト） | `src/core/player/growth.ts` |
| 初期能力・学年別ベース値 | `src/core/player/createPlayer.ts` |
| ランク表記（F〜S）の境界 | `src/core/player/rating.ts` |
| マスイベントの効果量 | `src/core/board/resolveCell.ts` |

## 確認方法

```bash
npx vitest run src/core/balanceCheck.test.ts --disable-console-intercept
```

3年分の成長曲線を出力する。数値をいじったら必ず実行して壊れていないか確認する。
**このスクリプトは「常に手札の先頭を選ぶ」無戦略プレイ**なので、実プレイの成長はこれより速くなる。出る数字は下限の目安。

## 現在の基準値（2026-08-01 時点）

無戦略プレイ・シード20260801での3年間：

| 時点 | 平均総合 | 平均ミート | 平均体力 | 1年生野手の総合 |
|---|---|---|---|---|
| 開始 | 38.7 | 30.6 | 84.6 | 19 |
| 1年後 | 46.7 | 44.4 | 94.0 | 32 |
| 2年後 | 53.2 | 49.1 | 44.0 | 42 |
| 3年後 | 56.7 | 49.9 | 40.0 | 45 |

- 1ヶ月あたりのカード使用枚数：**4.9枚**（盤面13マス ÷ カード平均2.7）
- 狙い：1年生が3年間で **G〜F → D〜C ランク** に届く。戦略的に選べば B 以上も狙える。

## 決めた理由の記録

### 成長の端数は確率で切り上げる
`+2.4` なら 40% で +3、60% で +2。切り捨てだと補正が細かく効かず、
やる気や学年の差が体感できなくなるため。

### 能力が高いほど伸びにくい（`diminishingMultiplier`）
70以上で ×0.75、80以上で ×0.5、90以上で ×0.3。
カンストを緩やかにし、後半の1ポイントを重くするため。

### 体力消耗は「カードを使った時点」で必ず発生させる
当初は練習マスに止まった時だけ消耗させていたが、それだと
**体力が常に100に張り付き、休養カードと体力管理が完全に無意味になった**（実測で平均体力100.0）。
マスに関係なく部活動自体は行っているため、カード選択時に消耗させるのが正しい。
→ `applyCardCost()` が担当。`applyPractice()` は能力上昇のみを扱う。

### 練習マスの出現率は42%
成長が主軸であることを伝えるため最頻にする。ただし高すぎると
すごろくの起伏がなくなるので、良イベント14% / 悪イベント12% / 空きマス14% を確保している。

## 世代交代を挟んだ長期バランス（2026-08-02 時点）

無戦略プレイ・8シードの平均。`npx vitest run src/core/seasonBalance.test.ts --disable-console-intercept`

| 時点 | 平均総合 | 最高総合 |
|---|---|---|
| 開始 | 35.9 | 55.6 |
| 1年後 | 33.2 | 50.6 |
| 3年後 | 33.5 | 50.6 |
| 6年後 | 34.0 | 50.1 |

**狙い：開始時の水準（平均36 / 最高56）を無戦略プレイでほぼ維持できること。**
これを下回りすぎると「何をしてもチームが弱くなる」体験になり、
上回ると育成の意味が薄れる。実プレイでは休養・黄マスを使えるので上振れする。

### 実際に起きた衰退バグ（2件）
1. **新入生の実力補正の基準がずれていた。**
   `(reputation - 45) * 0.3` としていたため、初期評判20では毎年 -8 の補正がかかり、
   世代を重ねるごとにチームが弱くなっていた（平均総合 37 → 24）。
   → **初期評判を補正0の基準にする**（`reputation - REPUTATION_INITIAL`）。
   評判は「上げれば良くなる」ボーナスとして働かせ、罰にしない。

2. **練習試合の相手が絶対値で固定されていた。**
   相手は常に初期チーム相当の強さだったため、こちらが衰えると一方的に負け続けた。
   → 相手の強さを**こちらの平均総合に追従**させる（`relativeStrength()`）。

### 成長量の引き上げ（1.5倍）
3年間で初期3年生（総合55前後）の水準に届かせるため、練習の基本上昇量を約1.5倍にし、
学年補正も 1年 1.2→1.35 / 2年 1.0→1.1 に上げた。
これが無いと、1世代3年では初期メンバーの水準に追いつけない。

## 大会（2026-08-02 実装）

### 回戦数は地区で決まる
`ceil(log2(参加校数))`。神奈川(178校)=8勝、鳥取(24校)=5勝。
ゲーム開始時の所在地選択が、実質の難易度選択になっている。

### 相手の強さ
```
-8 + (回戦の進行度 0〜1) × 30 + 地区補正 + 大会の格
```
- 1回戦は格下（-8前後）、決勝は格上（+22前後）。
- 地区補正 `(log2(参加校数) - 6) × 3` … 神奈川 +4 / 鳥取 -4。
- 大会の格 … 全国大会 +10 / 秋季大会 -4。
- **大会の相手はこちらの実力に追従させない。** 練習試合と違い、
  大会は育成の成果を測る場なので難易度は絶対値で固定する。

### 世代を超えた成長ループ（無戦略プレイ・8シード平均）

| 時点 | 平均総合 | 最高総合 |
|---|---|---|
| 開始 | 36.2 | 55.6 |
| 3年後 | 36.2 | 50.3 |
| 6年後 | **40.8** | **56.5** |

大会実装前は6年後も34前後で横ばいだったが、
**「大会で勝つ → 評判が上がる → 良い新入生が来る → さらに勝てる」**
という正のループが働くようになり、緩やかな右肩上がりになった。
無戦略プレイでこの伸びなので、実プレイはさらに速い。

### 引き分け敗退のバグ
当初、大会でも12回打ち切りの引き分けが起こり、**引き分け＝敗退**として処理されていた。
トーナメントで引き分け敗退は不当なので、大会の試合は `decisive: true` とし、
10回からタイブレーク（無死一・二塁開始）で必ず決着をつけるようにした。

## 冬合宿・春の全国大会（2026-08-02 実装）

### 合宿の効果
通常の練習の **5回ぶん**（`CAMP_MULTIPLIER = 5`）を1度にまとめて入れ、
その後 1.5倍×3回 の練習効率バフが残る。体力は12〜40消費する。
年に1度しか無いので、これくらい大きくないと「合宿らしさ」が出ない。

### 評判の効果を 0.3 → 0.18 に引き下げた
合宿と春の全国大会を入れたことで評判が伸びやすくなり、
評判が上限近くまで行くと **新入生が前の代の3年生と同じ能力で入学**するようになった。
3年かけて育てる意味が消えるため、`talentFromReputation` の係数を下げた。

| 設定 | 6年後の平均総合 | 6年後の最高 |
|---|---|---|
| 合宿・春の全国なし | 40.8 | 56.5 |
| 係数0.3（runaway） | 56.3 | 77.1 |
| **係数0.18（採用）** | **45.6** | **64.3** |

無戦略プレイで6年かけて 平均36→46 / 最高56→64。
右肩上がりだが飽和せず、3年間の育成の手応えも残る水準に落ち着いた。

## 部費（2026-08-02 実装）

### 収入と支出の目安
- 毎月：8,000円 + 評判×400円。評判20で **16,000円/月**、評判100で 48,000円/月。
- 大会：1勝 8,000円 ＋ 優勝ボーナス（地区4万／春全国10万／夏全国15万）。
- 1年の収入は、評判20で約19万円、評判60で約40万円＋大会賞金。

支出の目安：
- スポーツドリンク 12,000円（体力+25）… 月1回買える水準
- 練習器具一式 40,000円（1.5倍×5回）… 2〜3ヶ月ためて買う
- 最新トレーニング機器 80,000円（2倍×4回）… 大会で勝った年に手が届く

**勝つと部費も増える**ので、評判と並ぶ2つ目の「勝利の報酬」になっている。
逆に言えば、勝てない年は買い物もできない。

### コンバートの上限をAにした理由
S（本職）まで上げられると、全員を好きな位置に置けてしまい
ポジション適性という仕組み自体が意味を失う。
サブポジは本職を超えない、という前提を守るため上限をAにした。

> 2026-08-02: コンバートは部費で買う方式をやめ、練習方針で指示する方式に変えた。
> 1段階に練習8回。G→Aで6段階＝48回で、1年（約50手）をほぼ丸ごと使う計算になる。
> その間は通常の練習が0.7倍になるので、「誰を転向させるか」の判断は残っている。

## 性格・施設・転生OB（廃止）・固定イベント（2026-08-02 実装）

### 6年後の到達点（無戦略プレイ・8シード平均）

| 実装時点 | 6年後の平均総合 | 6年後の最高 |
|---|---|---|
| 大会まで | 40.8 | 56.5 |
| 合宿・春の全国まで | 45.6 | 64.3 |
| **今回の5機能を追加** | **52.1** | **76.1** |

5機能ぶんの上乗せが +6.5。いずれも強化要素なので上がるのは想定どおりだが、
**一度やり過ぎて 57.2 まで跳ねた**ので下げている（下記）。
なお診断はグラウンドもマネージャーも買わないので、実プレイはこれより速い。

### 転生OBを弱めた（※ 2026-08-02 に機能ごと廃止）
当初は生前の総合の **80%** を引き継ぎ、総合55以上の卒業生が対象、出現率25%だった。
評判が上限に張り付く後半では、ほぼ完成した選手が毎年のように入学し、
**育成が要らなくなる**（6年後の平均総合が46→57）。

→ 引き継ぎ 50% ／ 対象は総合65以上 ／ 出現率18% に下げたが、
最終的には機能ごと取りやめた（理由は docs/game-design.md）。
代わりにライバル校とスカウトを置いている。

### 固定イベントのマイナスを軽くした
中間・期末試験 -12 → -8、猛暑 -15 → -10。
**プレイヤーが避けようのないイベント**に大きなマイナスを置くと、
理不尽になるだけで判断の余地が生まれない。実測でも平均体力が
一時0まで落ちる年があったため下げた。

### 性格の配分
「どれが強い」ではなく得意分野が違うようにした。
成長倍率を持つのは天才肌(1.18)とやんちゃ(1.12)だけで、
残りは体力・信頼度・試合など別の軸で得をする。
そのぶん天才肌はやる気の影響が1.5倍、やんちゃは体力消費が1.3倍という代償がある。

## ルート分岐と怪我（2026-08-02 実装）

### ルート分岐の配分
| 道筋 | 主な内訳 |
|---|---|
| 練習の道 | 練習55% / 黄12% / 緑10% / 青8% / 赤8% |
| 挑戦の道 | 赤24% / 練習18% / 特16% / 青16% / 試14% / OB12% |
| 休養の道 | 緑34% / 練習26% / 青14% / 赤4% |

**挑戦の道は赤24%と高い**が、特訓・OB・試合が合計42%ある。
体力に余裕がある時に選ぶ、というトレードオフを成立させるための配分。

### 怪我
- 発生源は赤マスの4分岐のうち1つ（＝赤マスに止まって約25%）。
- **体力が低い選手ほど選ばれやすい**（重み `110 - 体力`）。
  体力管理を怠ることの罰を、能力の伸び以外の形でも与える。
- 離脱1〜3ヶ月。離脱中は練習で伸びず、体力も減らず、スタメンから自動で外れる。

## 部員数拡大・偶発性・卒業後の進路（2026-08-02 実装）

### 6年後の到達点（無戦略プレイ・8シード平均）

| 実装時点 | 平均総合 | 最高総合 |
|---|---|---|
| 前回（部員15人・偶発性なし） | 45.6 | 64.3 |
| **今回（部員24〜40人・急成長/スランプあり）** | **52.5** | **83.8** |

上がった理由は2つで、どちらも意図した結果：
1. **部員が増えた** … 母数が増えるぶん、飛び抜けた選手（外れ値）が出やすい
2. **急成長がある** … 練習の逓減を受けずに伸びる経路ができた

「突然上達する選手が出る」ことが狙いなので、最高値が伸びるのは想定内。
ただし完成した選手が +13 を繰り返すと天井が無くなるため、
**能力が高いほど急成長の伸び幅を絞っている**（90以上で1/4）。
これを入れる前は最高86まで行った。

### 急成長とスランプの釣り合い
発生率は上下とも5%/月、変動する能力数も2〜3で揃えた。
当初は急成長を優遇していたが（5% vs 4%、2〜3個 vs 1〜2個）、
それだと**練習しなくても勝手に伸びる**状態になり、練習の意味が薄れる。
振れ幅を出すのが目的であって、平均を上げるのが目的ではない。

### ベンチ入り／ベンチ外
上位20人がベンチ入り、それ以外は練習効率75%。
部員が40人規模になっても全員が均等に育つと不自然なため。
離脱中の選手はベンチの枠を占有しない。

### 卒業後の進路のしきい値
| 進路 | 卒業時の総合 |
|---|---|
| プロ入り | 76以上 |
| 大学進学 | 58以上 |
| 社会人 | 44以上 |

無戦略プレイの6年後で最高83なので、**直接プロに行けるのは主力級だけ**。
大学経由なら4年間で伸びてプロに届く可能性があり、
「高卒では届かなかった選手が大学で化ける」という筋が通る。

## 遠征費（2026-08-02 実装）

### 5年ぶんの実測（無戦略プレイ・6シード平均）
```
[nara]     5年 収入2781k 遠征費318k（16.3回）
[kanagawa] 5年 収入2653k 遠征費697k（15.0回）
[miyagi]   5年 収入2929k 遠征費959k（17.5回）
[okinawa]  5年 収入3341k 遠征費1217k（12.5回）
```
甲子園に近い順に並べてある。**奈良（会場が地元）と沖縄で約900kの差**が出た。
沖縄は回戦数が少ない（6勝）ぶん全国に出やすく、出るたびに遠征費がかさむ。
「勝ち抜きやすいが遠い」「勝ち抜きにくいが近い」という取引が成立している。

### 甲子園までの遠征費（初戦ぶん）
| 所在地 | 距離 | 初戦費用 | 初戦収支（補助込み） | 優勝時の収支 |
|---|---|---|---|---|
| 奈良・大阪など近畿 | 0 | 0 | +100,000 | +730,000 |
| 愛知・四国 | 3 | 72,900 | +27,100 | +387,100 |
| 神奈川・関東 | 6 | 91,800 | +8,200 | +368,200 |
| 九州 | 8 | 104,400 | -4,400 | +355,600 |
| 東北 | 11 | 123,300 | -23,300 | +336,700 |
| 北海道 | 17 | 161,100 | -61,100 | +298,900 |
| 沖縄 | 19 | 173,700 | -73,700 | +286,300 |

**どの地区でも優勝すれば黒字**になるようにしてある（travel.test.ts で検証）。
遠い地区が優勝しても赤字になる状態は、勝利が罰になるので採らない。

### 全国大会の賞金を1勝80,000円に上げた
当初は全大会共通で1勝8,000円だったが、1泊ぶんの宿泊費が54,000円（18人×3,000円）
なので、**勝ち進むほど赤字**になっていた。勝ちたくないという歪んだ動機が生まれるため、
1勝の賞金が1泊の宿泊費を上回るよう夏の全国を80,000円、春を60,000円に引き上げた。

### 出場するだけの遠征補助を足した
補助が無いと初戦敗退が丸損になり、「全国に出た」こと自体が罰になる。
夏100,000円／春80,000円を出場時点で支給し、近い地区なら初戦敗退でも黒字にした。

## 毎月の維持費（2026-08-02 実装）

### 数値
- 備品費：部員1人あたり **400円/月**
- 設備維持費：(グラウンドLv − 1) × **6,000円/月**（Lv1は0円）

| 状態 | 維持費/月 | 支給/月 | 差引 |
|---|---|---|---|
| 初期（部員24人・Lv1・評判20） | 9,600 | 16,000 | +6,400 |
| 中盤（部員30人・Lv3・評判60） | 24,000 | 32,000 | +8,000 |
| 終盤（部員40人・Lv5・評判100） | 40,000 | 48,000 | +8,000 |

**どの段階でも差引は+6,000〜8,000円程度**になるよう調整した。
規模が大きくなると支給も増えるが、維持費も同じだけ増えるので手元には残らない。
月々の支給は「部の維持に消えるお金」、大会の賞金は「強化に使えるお金」という役割になる。

### 5年ぶんの実測（無戦略プレイ・6シード平均）
```
[nara]     収入2781k 遠征費318k  維持費658k 残高952k  未払い0.0回
[kanagawa] 収入2610k 遠征費703k  維持費658k 残高961k  未払い0.0回
[miyagi]   収入2929k 遠征費959k  維持費663k 残高963k  未払い0.0回
[okinawa]  収入3341k 遠征費1217k 維持費676k 残高1000k 未払い0.0回
```
維持費が658k（収入の約24%）、遠征費と合わせて **収入の37〜57%が固定費**になった。
自動プレイはグラウンドを整備しない（Lv1のまま）ので、維持費は備品費だけの値。

**未払いは120プレイ年で0回**。序盤に赤字になって信頼度が下がり続ける事故は起きない。

### 整備を「維持費を背負う決断」にした
グラウンドの整備は払い切りの強化だったので、部費さえ貯まれば必ず上げるのが正解だった。
維持費を付けたことで「上げたあと払い続けられるか」を考える必要が出る。
整備ボタンには増える維持費（+6,000円/月）を必ず表示する。

1段階ぶんの維持費を1年払っても72,000円で、Lv2の整備費150,000円より安い。
維持費が重すぎて整備自体が損になる、という状態は避けている。

### 払えないときの扱い
払える範囲だけ払い、**全員の信頼度が3下がる**。借金は作らない。
信頼度は良イベント(+5)や試合(+4)で戻るので、-3/月は詰みではなく圧力にとどまる。

### 診断で収支を測るときの注意
月ごとの残高の増減で測ると、賞金と遠征費が**同じ月に相殺されて支出がほぼ0に見える**
（実際にそう見えて「効いていない」と誤判断した）。
`seasonBalance.test.ts` のように **ログから項目ごとに拾う**こと。
ログは50件で切り捨てられるので、年ごとではなく**毎月**走査する必要もある。

## 盤面を1マス1日にした（2026-08-02）

### 手数と成長速度は直結している
1マス1日・1年365マスに変えた直後、カードの数字が1〜5のままだったため
1年の手数が約55手 → 約120手に倍増し、**成長が一気に速くなった**。

```
（カード1〜5のまま）1年後 平均48.5 最高83.5 ／ 2年後 平均58.5 最高96.8
```
2年目で能力が上限近くに達してしまい、3年間の育成という前提が壊れていた。

カードの数字を **3〜12（平均7日）** に変えて手数を約50手に戻したところ、
月ごとの盤面だった頃とほぼ同じ曲線に収まった。

```
1年後 平均37.5 最高64.8 ／ 2年後 平均44.0 最高77.9 ／ 6年後 平均52.4 最高89.6
（変更前の月盤面: 1年後 37.6 ／ 2年後 40.8 ／ 6年後 49.8）
```

**カードの数字は1年の手数＝練習回数を決める最重要の値。**
触るときは必ず `seasonBalance.test.ts` を回すこと。

> のちに1マス3日・カード1〜5に刻み直した（下記「難易度の引き締めと盤面の刻み直し」）。
> 手数は約49手のままで、**数字の見た目だけを読みやすくした**。

### 遠征費と維持費は据え置きで問題なかった
1年の月数は変わっていないので、維持費（月あたり）はそのまま。
遠征費は練習試合マスに止まる回数が少し増えたぶん増えたが、収入も増えており
残高が枯れることは無かった（未払い0回）。

## 選手ごとの練習方針（2026-08-02 実装）

### 倍率
| 方針 | 指定した能力 | それ以外 |
|---|---|---|
| チーム練習（既定） | 1.0 | 1.0 |
| 能力を指定 | **1.6** | **0.6** |
| コンバート | — | **0.7** |

指定した1つが1.6倍でも、他5つが0.6倍になるので**チーム全体の合計は下がる**。
「主力を1人尖らせる」か「全員を満遍なく伸ばす」かの選択になり、
全員に指定して得をする、という抜け道は無い。

自主練（チームの練習内容に無い能力の伸び）は基本量2.5と小さくしてある。
ここを大きくすると、カードの練習内容を選ぶ意味が薄れる。

### 長期バランスへの影響は無い
診断（無戦略プレイ）は方針を指定しないので、数値は変更前と同じ。
**この機能は完全に任意**で、使わなければ従来どおりに進む。
実プレイでは主力を尖らせるぶん上振れするが、そのぶん他が鈍るので暴走はしない。

## グラウンドLv1〜99・カード拡張・評判グレード（2026-08-02 実装）

### 6年後の到達点（無戦略プレイ・8シード平均）
```
0年後 平均35.6 最高56.1 グラウンドLv1
1年後 平均41.0 最高70.6 グラウンドLv5
3年後 平均46.5 最高78.0 グラウンドLv8
6年後 平均55.3 最高86.9 グラウンドLv12
```
前回（6年後 平均52.4）から +3。理由は2つで、どちらも意図した結果：
1. **「グラウンド整備」カードが無料で設備を上げる** … Lv12前後で荒れと釣り合う
2. **カードが18種類になった** … 体力を戻すカードが増え、平均体力が上がった

一度 study +5 / outing +22 / medical +10 と回復を大きくしたら 6年後 56.6 まで伸びたので、
それぞれ +2 / +15 / +4 に下げた。**休養カードの立場を奪わない範囲**に収めるのが基準。

### グラウンドの荒れと整備の釣り合い
- 荒れる確率 = `0.05 + Lv × 0.0025`（Lv1で5%、Lv99で約30%）。維持費未払いの月は2倍。
- 1回で1〜2段階下がる。
- 「グラウンド整備」カード（重み3／全体の約5%）だけで **Lv10〜12 で釣り合う**。
  そこから先は部費を使わないと上がらない、という設計どおりの動き。

### 整備費を `3,000円 × 現在のLv` にした理由
Lv99までの累計が約1,450万円になる。無戦略プレイの5年間の収入が約300〜600万円なので、
**部費が余る問題がこれで解消**する。段階が上がるほど高くなるので、
「どこまで上げて維持するか」が長期の判断になる。

### 評判を G〜S にした
星1〜5では段階が粗く、評判が上がった手応えが出にくかった。
能力値と同じ8段階にして、手札の枚数（4〜8枚）と結びつけた。
**能力を直接盛るのではなく選択肢を増やす**形の報酬にしている。

## 練習器具（2026-08-02 実装）

### 価格と故障率
| 器具 | 価格 | 故障率/月 | 期待寿命 |
|---|---|---|---|
| ティースタンド | 60,000円 | 10% | 約10ヶ月 |
| ラダー | 80,000円 | 9% | 約11ヶ月 |
| ベンチプレス | 120,000円 | 5% | 約20ヶ月 |
| ビデオ機材 | 140,000円 | 8% | 約12ヶ月 |
| ブルペン | 160,000円 | 6% | 約17ヶ月 |
| ピッチングマシン | 200,000円 | 12% | 約8ヶ月 |

**1年〜1年半で買い直しが必要**な水準。毎月の支給（16,000〜48,000円）に対して
1つあたり2〜6ヶ月ぶんなので、6つ全部を常時維持するのは高評判でないと難しい。
「どれを維持するか」の判断が残るように意図した配分。

故障率は価格に比例させていない。安い器具ほど壊れるようにすると
「安物買いの銭失い」の話になり、高い物を買えばいいだけの単純な選択になるため。

### 長期バランスへの影響は無い
診断（無戦略プレイ）は器具を買わないので、数値は変更前と同じ
（6年後 平均55.3 / 最高86.9）。**任意の強化**なので、使わなければ従来どおり。
器具の練習は通常より1項目あたりの伸びが大きいので、実プレイでは上振れする。

## 投手スタミナ・守備重要度・通算成績・スカウト・U18（2026-08-02 実装）

### 投手スタミナを「Dで5回」に合わせた

以前は `capacity = 12 + stamina * 0.35`（D=55 で30人＝7回相当）に加え、
交代の判定が `staminaFactor <= 0.75` と緩く、**毎試合ほぼ完投**していた。

`capacity = max(4, stamina * 0.47 - 4)` に変え、
交代の判定も `<= 0.96`（ほぼ限界ちょうど）にした。

実測（`staminaCheck.test.ts`、スタミナを固定した先発で120試合）:

| スタミナ | G(20) | E(40) | D(55) | C(65) | B(75) | S(90) |
|---|---|---|---|---|---|---|
| 平均投球回 | 1.7 | 4.1 | 5.7 | 6.7 | 7.8 | 8.9 |
| 完投率 | 0% | 0% | 0% | 0% | 13% | 66% |

スタミナが切れてからの倍率は下限0.5（以前は0.55）、
減衰も 0.02→0.03/打者に上げた。続投すれば確実に失点が増える。

### ポジションごとの守備の重み

チーム守備力を均等平均から**重み付け平均**に変えた。

| 位置 | 遊撃 | 二塁 | 捕手 | 中堅 | 三塁 | 右翼 | 一塁 | 左翼 | 投手 |
|---|---|---|---|---|---|---|---|---|---|
| 重み | 1.00 | 0.92 | 0.85 | 0.78 | 0.62 | 0.50 | 0.36 | 0.30 | 0.20 |

さらに適性 C より下で起用したぶんを `misplacement` として集計し、
失策率に `+0.005/点`、被安打率に `+0.004/点` を上乗せする。
遊撃にG適性を置くと 1.0×5 = 5点 → 失策率が約2倍になる。

同じ9人・同じ打順のまま守備位置だけを入れ替えた60試合の比較で、
失点が有意に増えることを `simulateGame.test.ts` で確認している。

### 試合での活躍による成長

安打1点・長打+1・本塁打+2・打点0.6・盗塁0.8、
投球はアウト0.25・奪三振0.5・自責-0.8で数え、3点で能力+1（1試合最大3）。

6年後の平均総合は 53.1 → 54.1、最高は 83.9 → 85.1。
**平均より最高が大きく動く**のが狙いどおり（試合に出る選手ほど伸びる）。

## 全国の強豪校・U18の全国比較・触れ込み・控えの起用（2026-08-03 実装）

### 全国の強豪校を持たせた

県内10校に加えて、**県外20校**を state に持つようにした。
1県に1校までにして全国に散らし、地力は県内より高くしてある
（県大会を勝ち抜いてきた顔ぶれなので）。

| | 地力の範囲 |
|---|---|
| 県内（10校） | -10 〜 22（うち1校は必ず16以上） |
| 県外（20校） | 8 〜 34 |

30校ぶんのセーブは **約7.1KB**。選手データを持たず、
学校の戦力と注目選手2人だけにしているので膨らまない。

回戦ごとの難易度の曲線（`opponentStrengthFor`）は変えていない。
`pickRivalFor` がその強さに近い学校を当てるだけなので、
全国大会1回戦の相手が急に強くなることはない。

### U18の選考を全国比較にした

以前は「県内でいちばん強い注目選手 +2」が基準だった。これには2つの問題があった。

1. **比較対象が1人しかいない。** その選手が卒業した年だけ基準が急に下がる。
   実測でも県内最強が 81 → 67 まで下がり続け、基準として使えていなかった。
2. **地区選択の難易度差が選考に乗る。** 参加校の多い県ほど強い選手がいるので、
   神奈川を選ぶと代表に選ばれにくい、という筋の通らない差がついていた。

全国の注目選手（上級生）を強い順に並べ、**代表枠18人目**を基準にした。
30校 × 2人 の中で上級生は約40人なので、その18番目が当落線になる。

実測（6シード平均・年度末時点で代表歴を持つ部員の人数）:

| | 1年後 | 2年後 | 3年後 | 4年後 | 5年後 | 6年後 |
|---|---|---|---|---|---|---|
| 代表経験者 | 0.0人 | 1.0人 | 2.2人 | 2.0人 | 2.2人 | 2.0人 |
| 当落線 | 77 | 75 | 75 | 75 | 75 | 75 |
| 自校の最高総合 | 74 | 81 | 88 | 90 | 92 | 91 |

当落線が 75 で安定するようになった（以前は 67〜81 で揺れていた）。
床（`U18_BASE_RATING = 75`）とほぼ一致しているので、
**床と相対評価が同じ水準を指している**ことも確認できている。

### スカウトの候補に触れ込みを付けた

素質どおりの能力しか持たず、推薦入学（+14）との差別化が
「事前に姿が見える」ことだけだった。候補に**特殊能力**を持たせた。

- 素質58以上の候補は25%で金特、それ以外は55%で青特
- **赤特は付けない。** わざわざ通う理由を作るための仕組みなので、
  良い面だけを見せて、代わりに獲るのが難しいという形にする
- 獲れば入学時から持っている

### 大差の試合で控えを出す

代打の判断は「7回以降の競った場面で打力の高い控えを出す」なので、
**育てたい下級生には一度も出番が回らなかった**。

7点以上開いたら控えの下級生に代える。リードしているときは7回から、
負けているときは5回から（勝っている試合で早々に主力を下げると追いつかれる）。
守備適性は `misplacementPenalty <= 1.0` まで許す
——**重要な位置ほど厳しい**ので、遊撃はDまで、左翼ならEでも通る。

1年ぶん（6シード平均）で打席が回った控えの人数:

| | 導入前 | 導入後 |
|---|---|---|
| 控え11人中 出場 | 2.5人 | 4.2人 |

ベンチ入りを決める判断に「誰を育てたいか」が乗るようになった。

## 遠征の相手・対戦成績・歴代記録・セーブ枠（2026-08-03 実装）

### 遠征の練習試合も学校から引く

遠征先の相手だけ使い捨ての名前のままだった。
行き先の県に学校があればそこから引き、**行き先も学校のある県を優先する**。
県外20校が48県に散っているので、優先しないと4割ほどしか当たらない。

### 学校ごとの対戦成績

`RivalSchool.record` に通算成績と直近の対戦を残す。
試合前の確認画面に「通算2勝3敗／前回：1年目 神奈川 夏の大会 準決勝で敗戦」と出す。
**判定には一切使わない**。勝ち上がりに記憶を乗せるだけの記録。

大会の組み合わせは毎回引き直しなので、
「去年の決勝の相手と再戦」のような筋書きにはならない。
当たった相手が過去に当たっていれば分かる、という程度。

### 歴代ベストナイン

卒業生にも高校3年間の通算成績（`Alumnus.highSchool`）を残し、在校生と並べる。

| 条件 | 値 | 理由 |
|---|---|---|
| ベストナインの最低出場 | 5試合 | 1試合だけの打率10割で1位にならないように |
| 率の部門の最低打数 | 50打数 | 規定打席にあたる下限 |
| 率の部門の最低投球回 | 30回（90アウト） | 規定投球回にあたる下限 |

**本職の位置でだけ競わせる。** 守れる位置すべてで候補にすると、
打てる選手が9枠を独占して「ナイン」にならない。

ベストナインの点数は、投手が `投球回×0.6 + 勝利×4 + 奪三振×0.3 - 防御率×6`、
野手が `OPS×100 + 試合×0.6 + 本塁打×2 + 打点×0.4`。
**積み上げ（試合数）と質（率）の両方**を見ないと、
3年間出続けた凡庸な選手か、1年だけ活躍した選手のどちらかに偏る。

### セーブの枠

3枠に増やした。**1枠目のキーは1スロットだった頃と同じまま**
（`hs-baseball-sim:save:v1`）にして、既存のセーブをそのまま読めるようにしている。

### BGM は作って取りやめた

Web Audio でコード進行を合成するBGMを一度実装したが、
長時間流すには単調で「無いほうがまし」という判断になり、削除した。
効果音だけを残している（docs/game-design.md）。

## スカウトの訪問制・学校の変更・データ画面（2026-08-04 実装）

### スカウトを「県を選ぶ」形にした

以前は10月に候補が自動で挙がり、1人ずつ費用を払って口説く形だった。
これだと**どこの誰なのかが分からず**、部費を払う判断が「高い／安い」だけになる。

行き先の県を選ぶ形に変え、**出張費を距離で決める**ようにした。

| 神奈川から | 神奈川 | 静岡 | 大阪 | 広島 | 福岡 | 沖縄 |
|---|---|---|---|---|---|---|
| 出張費 | 8,000円 | 13,400円 | 18,800円 | 26,000円 | 42,200円 | 62,000円 |

月の部費は評判20で16,000円、評判95で46,000円。
地元1回が月の部費の半分、沖縄1回が弱小校の4ヶ月ぶんになる。

**1回の出張で会えるのは1人だけ。** これで「10人の中から誰に会うか」が
毎回の判断になる。以前のように費用を払える限り全員に会えると、
候補を並べる意味が無くなる。

評判ごとの候補の質（1県10人の平均素質と最上位）:

| 評判 | 平均素質 | 最上位 | 中位候補の見込み（0回→4回） |
|---|---|---|---|
| 20（弱小校） | 39.9 | 48 | 12% → 60% |
| 40（中堅校） | 40.0 | 48 | 22% → 70% |
| 60（有力校） | 44.1 | 50 | 31% → 79% |
| 80（名門校） | 46.7 | 58 | 40% → 88% |
| 95（全国屈指） | 52.4 | 62 | 47% → 90% |

### 県ごとの傾向

出張費を払う前に**行き先を選ぶ材料**が要る。
「長距離砲の産地」「投手王国」などを県ごとに持たせ、
**候補の生成にも実際に効かせている**。表示だけの飾りにすると、
書いてあることと出てくる選手が食い違って信用されなくなる。

傾向は新規ゲームで一度だけ決まる。途中で変わると
「あの県は投手王国だった」という覚え方ができない。

### 会いに行かなかった候補にも結末を出す

視察した県の候補は**全員**進学先が決まる。
「あのとき通っていれば」が後から分かるようにするため。

ただし他校の注目選手として抱えさせるのは**素質50以上だけ**。
10人×訪問県ぶんを全部残すとセーブが膨らむ。
世代交代の画面に出すのも会いに行った候補だけで、
残りは「データ」画面で確認する。

### 学校の変更

年度の切り替わりでだけ、学校名・ユニフォーム・所在地を変えられる。
**所在地を変えると県内のライバル校を作り直す**が、
県外の全国クラスはそのまま残す（甲子園で当たってきた相手を消すと、
せっかく積み上げた対戦成績が意味を失う）。

ユニフォームは学校名のハッシュから導くのをやめ、6色から選ぶ形にした。
導いていた頃は、学校名を変えると色まで変わってしまっていた。

## 難易度の引き締めと盤面の刻み直し（2026-08-05 実装）

「能力も評価も上がりやすすぎる。プロ入りがそう簡単に出ては困る。
総合Sになるのは10年に一人くらい」という指摘を受けての全面調整。

### 盤面を1マス3日にした

1マス1日のままカードの数字を3〜12にしていたが、**数字が大きすぎて読みづらかった**
（手札に「11」と書かれたカードが並んでも、11がどれくらい進むのか感覚が掴めない）。

1マス＝3日（`DAYS_PER_CELL = 3`）に変え、1年を **122マス**（`CELLS_IN_YEAR`）にした。
カードの数字は **1〜5** に戻し、重みで平均を 2.5マス＝約7.5日に合わせている。

| 数字 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 重み | 12 | 26 | 28 | 20 | 14 |

1年およそ **49手**。3〜12だった頃（約50手）とほぼ同じで、成長速度は変えていない。
**数字の見た目だけを変えて、手数は据え置く**のが狙い。

> `boardPosition` の意味が「通算日」から「マス番号」に変わったので、
> セーブの移行（v22→v23）が必須だった。`cellOfDay()` で読み替えて盤面を作り直している。

### カードの出現率は練習7割

運営カード（メンタル・整備・勉強）の重みを 3→2 に下げ、
**練習系70.2%／それ以外29.8%** にした（実測 練習40種ぶん / その他17種ぶん）。
運営カードが多すぎると、練習マスに止まっても伸ばす能力を選べない手が続く。

### 成長の鈍化を強めた

`diminishingMultiplier` を段階ごとに厳しくした。

| 現在値 | 変更前 | 変更後 |
|---|---|---|
| 〜69 | 1.0 | 1.0 |
| 70〜79 | 0.7 | **0.5** |
| 80〜84 | 0.45 | **0.28** |
| 85〜89 | 0.3 | **0.16** |
| 90〜 | 0.15 | **0.08** |

70から先が目に見えて重くなり、90を超えるとほとんど動かない。

### 評判は上に行くほど上がりにくい

加算量に `(1 - 現在値/100)^2` を掛ける（`reputationGainAt`）。

| 現在の評判 | 加算の通り具合 |
|---|---|
| 20 | 90% |
| 50 | 60% |
| 80 | 26% |
| 95 | 9% |

以前は1年目で評判100に到達していた。いまは1年後60、6年後86。
**全国屈指（90以上）は何年も勝ち続けた学校だけ**が届く水準になった。

### 進路の閾値を上げた

| 進路 | 変更前 | 変更後 |
|---|---|---|
| プロ | 74 | **82** |
| 大学 | 56 | **62** |
| 社会人 | 42 | **46** |

評判ボーナスの係数も 0.1→**0.05** に下げた。強豪校ならプロが量産される状態を止める。

### 結果（10年・無戦略プレイ）

```
Sランク（総合90以上）… 10年で 0.0人
Aランク（総合80以上）… 10年で 2.8人
年ごとの最高総合 … 平均 73.7 ／ 全体最高 89

6年後 平均44.2 / 最高74.1（変更前は 平均51.3 / 最高85.5）
評判 1年後 60 / 6年後 86（変更前は1年後に100）
```

無戦略でSが出ないところまで落とした。実プレイでは練習方針・グラウンド・
器具・合宿が乗るので、**狙って育てれば10年に一人は届く**想定。

### 本塁打を締めた

長打のうち本塁打になる割合を、パワーと弾道から出す式に変えた。

```
0.03 + (パワー - 45)/500 + (弾道 - 2)×0.03   （0.004〜0.35 に収める）
```

| パワー / 弾道 | 本塁打率 |
|---|---|
| 30 / 1 | ほぼ0 |
| 50 / 2 | 4% |
| 80 / 3 | 13% |
| 95 / 4 | 19% |

1試合あたりの本塁打が **0.54 → 0.34本**。打率は .276 で変えていない。
能力の低い選手がスタンドまで運ぶことが無くなった。

### 本職投手は10人に2人

`PITCHER_RATE` を **0.18** に下げ、初期部員は各学年1人だけ投手を確約する
（以前は各学年2人＋確率だったため、投手が半数近くを占めることがあった）。
世代交代での最低確保数（`MIN_PITCHERS`）も 3→**2**。

実測の投手比率は12〜30%。少なすぎると継投が組めないので、下限は残している。

### 大会を回戦ごとのマスに割った

連戦式では、大会マスに止まると優勝か敗退まで盤面に戻れなかった。
**勝ち進むほど盤面が進まない**ので、強いチームほど1年の練習回数が減るという逆転が起きていた。

`placeTournamentCells()` で、開幕日のマスから `ROUND_GAP = 1` マス間隔に
回戦ぶんのマスを並べる。1つ勝つと `cardSelect` に戻り、次の回戦まで練習できる。

```
夏の地区大会（8回戦）… 35マス目（7/15）〜 42マス目（8/8）
秋季地区大会（6回戦）… 65マス目（10/15）〜 70マス目
```

春の全国大会だけ実際より早い **3月5日** に置いた。実際の日程だと
回戦ぶんのマスが年度末（3月31日）を越えてしまうため。

### 3年生は夏で引退する

夏の地区大会で敗退した時点（全国に出た場合は全国が終わった時点）で、
3年生をチームから外す（`retireThirdYears`）。秋以降は新チームで戦う。

**秋季大会を下級生だけで戦うことになる**ので、夏のうちに下級生へ経験を積ませるかどうかが
実際の判断になった。以前は3年生が3月まで居座り、秋も春も主力のままだった。

## 盤面を1マス1日に戻し、大会を育成の柱にした（2026-08-05 実装）

### 1マス3日をやめた理由

カードの数字を読みやすくするために1マス3日にしたが、
**盤面が「日めくり」に見えなくなった**。7月15日のマスが7月13〜15日のどこかになり、
大会の日程も合宿も日付として置いているのに、その日付が盤面から読めない。

1マス＝1日（365マス）に戻し、**カードの数字は1〜5のまま**にした。
読みやすさは保ったまま、盤面が日めくりに戻る。

### 増えた手数は1手あたりの効果で割り戻す

1年の手数が **約49手 → 約146手**（実測131.8手／年）に増える。
カード定義の `amount` は「1回の練習でこれくらい」という読みやすい値のまま残し、
**倍率を1か所に置いて割り戻す**。カードを全部書き換えるより、
刻みを変えたときにここだけ直すほうが追いやすい。

| 定数 | 値 | 何で割ったか |
|---|---|---|
| `PRACTICE_GROWTH_SCALE` | 0.25 | 練習マスの回数（13.4回 → 61回／年） |
| `CARD_COST_SCALE` | 0.30 | 手数そのもの（49手 → 146手） |

**2つが別の値になるのが正しい。** 成長は「練習マスに止まった回数」に比例し、
体力と信頼度は「止まったマスに関係なく毎手」かかるため。
どちらも計算値（0.22 / 0.33）から実測で少し緩めてある。

### 小さい値の四捨五入で性格差が消えた

1手あたりの体力消耗が2〜3という小さな値になり、`Math.round` で丸めたところ
**性格やマネージャーの2割の差が丸め込まれて消えた**
（-2.64 も -3.17 も同じ -3 になり、「やんちゃは消耗が激しい」が成立しなくなった）。
成長計算と同じ**確率で切り上げる**丸めに変えて解決した。

### マスの密度を組み直した

手数が3倍になると、重みが同じままでは**練習試合も特訓も怪我も年3倍**起きる。
練習マス以外は「1年に何回あってほしいか」から逆算し、増えたぶんは
練習マスと空きマス（＝何も無い日）が受け持つ。

| マス | 旧重み | 新重み | 年あたり（旧→新） |
|---|---|---|---|
| 練習 | 30 | **42** | 13.4 → 61 |
| 何も無い | 10 | **28** | 4.5 → 41 |
| 休養 | 9 | 5 | 4.0 → 7.3 |
| 青 | 12 | 4 | 5.3 → 5.8 |
| 赤 | 11 | 4 | 4.9 → 5.8 |
| 白 | 10 | 4 | 4.5 → 5.8 |
| 黄 | 8 | 4 | 3.6 → 5.8 |
| 練習試合 | 6 | 3 | 2.7 → 4.4 |
| 特訓 | 5 | 2 | 2.2 → 2.9 |
| OB | 4 | 2 | 1.8 → 2.9 |
| 分岐 | 5 | 2 | 2.2 → 2.9 |

実測（365マスの盤面）：練習139 / 空き104 / 青19 / 休養16 / 黄15 / 分岐14 / 赤12 /
OB10 / 白8 / 特訓6 / 練習試合6。

ルート分岐の範囲も10マス（＝10日）では短すぎるので **30マス（＝30日）** に戻した。
道筋の重みは、基本の盤面より特別なマスが厚くなるように組み直してある
（そうでないと分岐マスに止まる意味が無い）。

### 大会の回戦は中1日にした

1マス＝1日になったので、`ROUND_GAP` を 1 → **2**（中1日）に。
連日で決勝まで戦わせると、体力の回復も継投の判断も入る余地が無い。

- 夏の地区大会（最大8回戦）… 7/15 → 7/29。全国大会（8/12）に間に合う
- 秋季大会（6回戦）… 10/15 → 10/25
- 春の全国大会だけ 3/5 → **3/10** に。8回戦ぶん（15日）でも年度末を越えない

### 大会を最大の育成機会にした

大会は「積み上げた力を確かめるだけの場」だった。
1試合ごとの成長は練習試合と同じ倍率で、大会が終わっても何も起きなかった。

**1. 大会の試合そのものを重くした**（`MatchStage`）

| 舞台 | 倍率 | 1試合の上限 |
|---|---|---|
| 練習試合 | 1.0 | 3段階 |
| 地区大会 | **1.5** | 4段階 |
| 全国大会 | **2.0** | 5段階 |

**2. 大会が終わった時点でチームが伸びる**（`tournamentGrowth.ts`）

```
経験点 = (勝ち数 + 0.5 + 優勝なら2) × 大会の格
大会の格：夏の地区 1.0 ／ 秋季 0.9 ／ 春の全国 1.4 ／ 夏の全国 1.6
能力+1 に必要な経験点：2.5（スタメンは満額、ベンチ入りは半分）
```

| 結果 | 経験点 | スタメンの伸び |
|---|---|---|
| 初戦敗退 | **0** | なし |
| 3回戦敗退（3勝） | 3.5 | +1〜2 |
| 準優勝（7勝） | 7.5 | +3 |
| 地区優勝（8勝） | 10.5 | +4 |
| 全国優勝（6勝） | 13.6 | +5 |

**1勝もできなければ0にした。** 出ただけで伸びるなら「結果で伸びる」という筋が通らない。

**3. 勝ち上がると特殊能力が身につく**

経験点1点あたり2%（上限35%）。地区優勝で21%、全国優勝で27%。
スタメン9人なら2人前後に付く計算。
**金特は優勝したチームの、信頼度60以上の選手だけ**（特訓と同じ基準）。

> 秋季大会を夏より低く（0.9）したのは、新チームの腕試しという位置づけのため。
> 3年生が抜けた直後の大会で夏と同じだけ伸びると、引退の重みが薄れる。

### 結果（10年・無戦略プレイ）

```
6年後 平均46.0 / 最高76.5 / 体力61〜80
Sランク（総合90以上）… 10年で 0.5人
Aランク（総合80以上）… 10年で 2.5人
年ごとの最高総合 … 平均 74.4 ／ 全体最高 87
1年あたりのカード使用枚数 131.8
```

刻みを変える前（平均73.7・最高89・A 2.8人）とほぼ同じ曲線に収まっている。
**手数を3倍にしても成長速度は変えていない**ということ。
違うのは、伸びの一部が練習から**大会の結果**へ移ったこと。

## 評判の相対化・成績による能力変動・プロの物差し（2026-08-05 実装）

### 評判は「誰に勝ったか」で動く

勝てば +1、負ければ -1 の固定だったので、**誰と戦ったかが評判に関係しなかった**。
弱い相手を選んで勝ち続けるのがいちばん効率の良い立ち回りになっていた。

相手にも自校と同じ物差しの評価を持たせた（`core/season/matchReputation.ts`）。

```
自校の評価 = スタメン9人の平均総合
相手の評価 = 37 + opponentStrength
          （37 は createOpponent が使う GRADE_BASE の平均 (22+38+52)/3）
```

| 結果 | 式 | 互角 | 格上+20 | 格下-20 |
|---|---|---|---|---|
| 勝ち | 1.0 + max(0, 差)×0.20 | +1.0 | **+5.0** | +1.0 |
| 負け | -(0.4 + max(0,-差)×0.25 - max(0,差)×0.05) | -0.4 | -0.2 | **-5.4** |

負けの基本値を勝ちの半分にしたのは実測の結果。1.0にしていたら、
年に十数試合ある練習試合と大会で削られ続け、
**長期プレイで評判が一桁まで落ちて回らなくなった**（60年後に7、部費の未払いも発生）。

大会の1勝ごとの評判もここで動かすので、`reputationGain(tournament)` からは
勝ち数ぶんを外して**優勝ボーナスだけ**にした（そうしないと二重に加算される）。
これで「決勝で勝つ」と「1回戦で勝つ」が同じ重みにならない。

### 評判は上でも下でも鈍らせる

上限側だけ鈍らせていたところに「負けたら下がる」を足したので、
今度は下に張り付いた。**片側だけ鈍らせると逆側に張り付く。**

```
上がるとき … × (1 - 評判/100)^2    評判20で90% / 50で60% / 80で26% / 95で9%
下がるとき … × max(0.25, 評判/100) 評判20で25% / 50で50% / 100で100%
```

無戦略プレイの評判は 6〜25（下限なし）→ **29〜62**（下限あり）に落ち着いた。
以前の 87〜90 固定と比べれば厳しいが、これは「負けても下がらなかった」のが異常だった。

### 試合の能力変動は成績が引き金

勝った試合に1.2倍を掛けていたので、**4タコでも勝ちチームに居れば伸びた**。
チームの勝敗はその選手の出来ではないので、評価から外した。
代わりに凡打・三振・被安打・与四球を減点に加え、**悪ければ下がる**ようにした。

| 打撃 | 点 | 投球 | 点 |
|---|---|---|---|
| 安打 | +1.0 | アウト | +0.25 |
| 長打 | +1.0 | 奪三振 | +0.5 |
| 本塁打 | +2.0 | 自責点 | **-0.8** |
| 打点 | +0.6 | 被安打 | **-0.15** |
| 盗塁 | +0.8 | 与四球 | **-0.2** |
| 四球 | +0.3 | | |
| 凡打 | **-0.35** | | |
| 三振 | **-0.25** | | |

3点で1段階。落ち幅は伸び幅の **55%**、1試合で最大2段階まで。
1試合の不振で積み上げが崩れると、主力を試合に出すこと自体が怖くなる。

打率.270の打者が4打数で稼ぐ期待値は約 +0.57 点なので、
**平均的な打者は少しずつ伸びる**。落ちるのは実際に打てなかった試合だけ。

### プロ入りで物差しが変わる

高校の総合をそのままプロへ持ち込んでいたので、
卒業した年から一線級の成績を残し、「プロで通用するか」という段階が消えていた。

| | 割合 | 倍率 |
|---|---|---|
| ほとんどの選手 | 85% | **×0.5** |
| プロの水に合う | 12% | ×0.7 |
| 別格 | 3% | ×0.85 |

**スケールを変えたら、そのスケールを読む定数も全部直す。**
戦力外の閾値を高校基準（45）のまま残していたら、入団した年に全員が戦力外になっていた。

| 定数 | 高校基準 | プロ基準 |
|---|---|---|
| 戦力外 | 45 | **22** |
| 海外挑戦 | 88 | **62** |
| 出場率 | (能力-35)/55 | **(能力-20)/45** |
| 年ごとの変動 | -2〜+6 / -9〜+2 | **-1〜+4 / -6〜+1** |

`ProSeason` に `ability` を足して、年ごとの実力をOB名鑑でグラフ表示できるようにした。

### 天才肌を2%のレア性格に

6分の1で出ていた頃はどの学年にも数人いて、
いちばん伸びる性格が当たり前に手に入っていた。

| | 変更前 | 変更後 |
|---|---|---|
| 出現率 | 1/6（16.7%） | **2%** |
| 入学時の能力 | ±0 | **+8** |
| 成長倍率 | 1.18 | **1.40** |

引き当てた学年が特別に感じられないと、レアにした意味が無い。
やる気の影響が1.5倍という弱点はそのまま残してある。

### 県ごとのスカウト傾向を毎年引き直す

固定だったので、一度「投手王国」を見つけたら毎年そこへ行くだけになり、
**行き先を選ぶ判断が1年目で終わっていた**。
毎年引き直し、**必ず前年と違う傾向**にする（同じ値を引くと更新されたのか分からない）。

### 結果（10年・無戦略プレイ）

```
6年後 平均41.3 / 最高76.6 / 体力73
Sランク 0.0人 / Aランク 1.2人（10年あたり）
年ごとの最高総合 平均70.6 / 全体最高88
評判 29〜62（長期72年）
```

変更前（平均74.4 / A 2.7人）より厳しい。負けたら評判が下がる仕組みを入れた当然の帰結で、
無戦略プレイでは学校が育たない。勝てるようになれば評判も新入生も伸びる。

## 伸びやすさの個人差（2026-08-05 実装）

### 練習の結果が全員同じに見えていた

やる気・学年・体力・性格の補正は前からあった。それでも
**画面には誰を見ても「+1」しか出てこなかった**。

原因は2つ。

1. **丸めで差が消えていた。** 1マス1日にしたぶん1回の伸びを 0.25倍に薄めたので、
   健康な選手の raw はだいたい 1.0〜1.6 に収まる。整数に丸めると全員 +1 になる。
   補正の幅（やる気0.7〜1.3 など）が、丸めを跨ぐには小さすぎた。
2. **表示が能力ごとの集計だった。** 「ミート +1.0 ×6人」では誰が伸びたか分からず、
   平均を出すと全員が同じだけ伸びたようにしか読めない。

### 得意・苦手を持たせた

選手ごとに**得意2つ・苦手2つ**を決める（`Player.growthAptitude`）。

| | 倍率 |
|---|---|
| 得意 | 1.25〜1.6 |
| 標準 | 1.0 |
| 苦手 | 0.6〜0.8 |

平均は約1.04で、**チーム全体の成長速度は変えていない**。
raw が 0.6〜2.2 まで広がるので、丸めても +0 / +1 / +2 に割れる。

苦手を 0.5 まで下げた版も試したが、苦手な能力が事実上凍りついて
総合が伸び残った（年ごとの最高総合 平均70.1／全体最高81）。
0.6 に緩めて 平均70.8／全体最高88 に戻している。
**「遅い」であって「動かない」ではない水準**に置くこと。

### 結果（10年・無戦略プレイ）

```
6年後 平均41.8 / 最高71.3
年ごとの最高総合 平均70.8 / 全体最高88
（変更前：平均70.6 / 全体最高88）
```

全体の速度は変わらず、**同じ練習でも選手ごとに +2 / +3 / +4 と割れる**ようになった。

## 初期能力を上げ、成長を抑えた（2026-08-05 調整）

### 狙い

低いところから始めて長く伸ばす形だったので、**1年生が誰も使えなかった**。
3年間ずっと同じ顔ぶれで戦うことになり、
「どんな素材を採れたか」という判断が結果にほとんど響かない。

入学時を高めに取り、練習で伸びる量を抑えた。
**到達点は変えず、出発点だけを上げる**のが狙い。

| | 変更前 | 変更後 |
|---|---|---|
| `GRADE_BASE` 1年 | 22 | **28** |
| `GRADE_BASE` 2年 | 38 | **43** |
| `GRADE_BASE` 3年 | 52 | **55** |
| `PRACTICE_GROWTH_SCALE` | 0.25 | **0.19** |

### 忘れずに直すもの

`GRADE_BASE` は**相手チームの生成にも使っている**（`createOpponent`）。
3学年の平均が「強さ0＝互角」の基準なので、
`OPPONENT_BASE_RATING` を 37 → **42** に直さないと格付けがまるごとずれる。
テストにも「互角の基準が `GRADE_BASE` と揃っている」を足して、次に動かしたとき気づけるようにした。

### スカウトの階層

素質の水準も引き上げた。**通常の新入生 → 県の候補 → U15代表**の段差をはっきりさせる。

| | 素質の中心（評判20） | 幅 |
|---|---|---|
| 通常の新入生 | 28 | ±14 |
| 県の候補 | 34 → **38** | -10〜+14 |
| U15代表 | 50 → **60** | -8〜+12 |

**素質をそのまま入学時の総合にした。** 34を引いていたので、
「素質34」と書いてあった選手が総合22（＝ごく普通の新入生）で入ってきていた。
カードに出す数字と実際が食い違うと、出張費を払って通う判断が成り立たない。

素質が上がったぶん、連動する定数も引き上げた。

| 定数 | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| `GOLD_SKILL_MIN_RATING` | 58 | **64** | 代表がほぼ全員金特持ちになる |
| `RIVAL_STAR_MIN_RATING` | 50 | **56** | 逃した候補が全員注目選手として残る |

U15代表を4回通ったときの獲得率（素質61）は 評判20で16% / 60で38% / 95で57%。

### 結果（10年・無戦略プレイ）

```
0年後 平均40.2 / 最高59.9   （変更前 35.9 / 56.9）
6年後 平均44.2 / 最高72.3   （変更前 41.8 / 71.3）
年ごとの最高総合 平均70.2 / 全体最高87（変更前 70.8 / 88）
Sランク 0.0人 / Aランク 0.5人（10年あたり。変更前と同じ）
```

**出発点が +4.3、到達点はほぼ同じ。** 6年間の伸びは +5.9 → +4.0 に鈍っている。
長期（72年）でも 平均50.9 / 最高83 で、以前と同じ水準に収まっている。

## 投手の疲労と大差の交代（2026-08-05 実装）

### 大差でも先発が投げ切っていた

「大差がついたら控えを出す」を**野手にしか入れていなかった**。
その結果、打線は控えなのにエースが最後まで投げているという試合になっていた。
勝敗が決した試合で主戦を消耗させる理由は無い。

野手と同じ場面判断（`isGarbageTime`）を投手交代からも呼び、
大差なら**下級生の投手**から出すようにした。
「良い2番手」ではなく学年の若い順にするのは、経験を積ませるのが目的だから。

実測（力の差が大きい試合、7点差以上がついたもの）：
**5割以上の試合で2人以上が登板**し、「経験を積ませる」交代が出る。

### 投手の疲労

体力（`condition`）とは別に、登板そのものの負荷を持たせた。
中1日で回戦が並ぶ盤面にしたのに、**2番手を育てる理由が無い**状態だった。

| | 値 |
|---|---|
| 溜まる | アウト1つで 60/27（完投で60） |
| 抜ける | 1日で12（完投から5日で万全） |
| スタミナの目減り | 疲労100で60% |
| 球威の低下 | 疲労100で15%（1人目の打者から効く） |

大会は中1日なので、**完投した投手は次の登板で疲労36が残る**。
効き方を「スタミナの目減り」に寄せたのは、レバーを1本にするため。
同じスタミナでも早く崩れる、という1つの説明で足りる。

回復は**日単位**（`selectCard` で進んだ日数ぶん）。
月ごとに戻す体力と違い、中1日でどれだけ抜けるかが勝負を分けるので、
月ではなく日で扱う必要があった。

### 連動して直したもの

- おまかせ編成：疲労55以上は先発から足切り、それ未満も疲労に比例して割引
- 継投：疲れた投手は候補の後ろへ回す
- 年度替わり：疲労を0に戻す（前年の連投を翌年まで引きずらせない）
- 試合前のスタメン確認：先発が疲れていれば警告を出す

### おまかせの投手枠が投球能力を見ていなかった

疲労を織り込んでも先発が変わらないので調べたところ、
**おまかせ編成の投手枠が守備適性と打力で選んでいた**ことが分かった。
球威も制球もスタミナも見ずに「打てる投手」が先発になっていたことになる。
`pitcherValue`（制球0.35＋スタミナ0.3＋変化球0.35）で選ぶよう直した。

実例（1回戦で完投した林が疲労29の状態）：

| 投手 | 投手力 | 疲労 | 評価 |
|---|---|---|---|
| 林 | 67.4 | 29 | 55.7 |
| 青木 | 62.0 | 0 | **62.0** |
| 松下 | 53.6 | 0 | 53.6 |

疲れたエースより、休んでいる2番手を立てる判断が自然に出る。

### 結果（10年・無戦略プレイ）

```
6年後 平均44.6 / 最高69.9
年ごとの最高総合 平均70.5 / 全体最高86
控え9.0人中 出場8.7人（変更前 8.8人中7.5人）
```

控えの出場が増えている。大差での投手交代が効いている。
スタミナ診断（単発試合・疲労0スタート）は変更前とほぼ同じ。

## 学年差を縮め、選手ごとの素質差を作った（2026-08-05 調整）

### 学年で序列が決まっていた

「強い1年生も、弱い3年生もいない」という状態だった。原因は2つある。

1. 学年差が大きすぎた（1年28 → 3年55 で27の開き）
2. **能力ごとの乱数（±14）が総合には効いていなかった**

2つ目が本質。`ABILITY_SPREAD` は6項目それぞれに独立して振るので、
平均である総合では打ち消し合って**±3程度に縮む**。
一方 `GRADE_BASE` は全能力をまとめて動かすので、そのまま総合に出る。
結果、総合を並べると必ず学年順になっていた。

### 直したこと

| | 変更前 | 変更後 |
|---|---|---|
| `GRADE_BASE` 1年 | 28 | **36** |
| `GRADE_BASE` 2年 | 43 | **44** |
| `GRADE_BASE` 3年 | 55 | **50** |
| `TALENT_SPREAD`（選手ごと・全能力） | なし | **±16** |
| `ABILITY_SPREAD`（能力ごと） | ±14 | **±10** |
| `PRACTICE_GROWTH_SCALE` | 0.19 | **0.11** |

**素質の幅（±16）を学年差（14）より大きく取る**のが要点。
全能力をまとめて上下させる軸なので、総合にそのまま出る。

成長は学年差を縮めたぶん下げた。3年間の伸びが
`GRADE_BASE[3] - GRADE_BASE[1]`（＝14）と釣り合っていないと、
3年生になった選手が初期3年生を大きく追い越してしまう。

連動して `OPPONENT_BASE_RATING` を 42 → **43**、
スカウトの県の候補を 38 → **46**（通常の新入生 +10 を保つ）に直した。

### 結果

新規開始時の総合（実測）：
```
1年: 52, 51, 47, 44, 42, 36, 29, 27, 26
2年: 56, 56, 52, 51, 47, 47, 36, 28
3年: 52, 50, 45, 44, 41, 39, 39, 34
```
1年の最高（52）が3年の最高（52）に並び、3年の最下位（34）が1年の下位より低い。
**学年が完全に混ざった。**

10年・無戦略プレイ：
```
0年後 平均42.1 / 最高61.1  （変更前 40.2 / 59.9）
6年後 平均46.5 / 最高75.8  （変更前 44.6 / 69.9）
年ごとの最高総合 平均73.5 / 全体最高89（変更前 70.5 / 86）
Sランク 0.0人 / Aランク 1.7人
```
上振れが出やすくなったのは素質差を入れた当然の帰結（強い素材が稀に来る）。

## 球速を伸びるようにし、重みを上げた（2026-08-05 実装）

### 球速がまったく伸びていなかった

`velocity` を `GrowableKey` から外していたので、
**入学時の値のまま3年間まったく動かなかった**。
そのうえ球威に占める比重が0.55と控えめで、球速を上げる意味が薄かった。

### 尺度を1本化した

球速は km/h の実数値で、他の能力（1〜100）と尺度が違う。
それを3か所で別々に変換していた。

| | 変換前の式 |
|---|---|
| `simulateAtBat` | 115〜160 → 0〜100 |
| `rating` | 120〜160 → 0〜100 |
| レーダー | 110〜160 → 0〜100 |

**同じ球速が画面と判定で違う意味になっていた。**
`types/player.ts` の `velocityScore()` に一本化し、
実際に出る帯（120〜148）に合わせて **115km/h で0、150km/h で100** に詰めた。
160を上限にしていた頃は、実際の球速が0〜73にしか広がらず、
球速の良し悪しが数字に出ていなかった。

### 数値

| | 値 |
|---|---|
| 生成 | `110 + 素質 × 0.5 + 学年 × 1.2` |
| 1年の平均 / 3年の平均 / 上位の3年 | 129 / 139 / 147 km/h |
| 上限 | 158km/h |
| 1点ぶんの伸び | 0.45km/h（`VELOCITY_GAIN_RATE`） |
| 球威に占める比重 | 0.55 → **0.7** |
| 総合に占める比重 | 0.3 → **0.4** |

伸びる練習は **走り込み（6）＞ ブルペン投球（4）＞ 投球練習（3）**。
下半身ができると球が速くなる、という筋で走り込みをいちばん厚くしている。

最初は `velocityScore` の逆算で生成していたが、素質の高い3年生が
**154km/h**（プロでも稀）に達したので、実際の高校生の帯に合わせて置き直した。

### 肩力は球速に比例させた

速い球を投げる腕が、送球だけ弱いということは無い。
`armFromVelocity`（`velocityScore + 5`）で導き、**投手の肩力は独立して育てない**。
投手が遠投を選んでも肩力は直接伸びず、球速を上げれば一緒に上がる。

これで投手のレーダーから肩力を外せた（球速と重複するため）。
軸は **球速／制球／変化／スタミナ／守備／走力**。
打撃で投手を評価しても意味が無いので、守備位置としての動きが分かる走力に替えた。

### 結果（10年・無戦略プレイ）

```
0年後 平均44.6 / 最高67.4  （変更前 42.1 / 61.1）
6年後 平均48.8 / 最高73.5  （変更前 46.5 / 75.8）
年ごとの最高総合 平均73.8 / 全体最高85
完投率 スタミナ75で23%→28%、90で75%→77%
```

投手の総合が上がったぶん平均が押し上げられている。
球速が伸びるようになったので、投手を育てる手応えが出た。

## 打順とベンチ入りの見直し（2026-08-06 実装）

### 球速の尺度を詰めたときの取りこぼし

打順を触る前に、**前回の球速調整で投手が一律に強くなっていた**ことが分かった。

`velocityScore` の上限を 160 → 150 に詰めたので、同じ投手の球速スコアが
平均 42.7 → 54.8（+12）に上がった。比重も 0.55 → 0.7 に上げたぶんと合わせて、
`stuff` が **43.0 → 51.4（+8.4）** 押し上がっていた。

狙いは「球速の重要度を上げる」ことで、投手の底上げではない。
`STUFF_BASELINE = 13` を引いて水準を戻した。

| | 打率 | 平均スコア |
|---|---|---|
| 球速調整の前 | .278 | 3.81 - 3.23 |
| 調整後（取りこぼし） | **.242** | 3.10 - 2.40 |
| 基準を戻したあと | **.271** | 3.97 - 2.67 |

**尺度を変えたら水準も動く。** 相対的な重みを変えたいだけのときは、
水準が動いていないかを必ず測ること
（`velocityScore` の範囲か `VELOCITY_WEIGHT` を触ったら測り直す）。

### 打順

打順ごとに見たいものを分けた（`core/lineup/battingTraits.ts`）。
式そのものより**決める順番**のほうが結果に効いた。

1. 9番（打力最下位）を先に抜く。上から埋めると最後に残った選手がたまたま打てる
2. 投手を8番へ（9番でなければ）。打力だけで決めるとミートの高い投手が2番に入った
3. 3番・4番を**2人まとめて**取り、長打力の高いほうを4番へ。
   1人ずつ選ぶとパワー型が先に3番を取る
4. 5番 → 1番 → 2番 → 6・7・8番

実測（新規開始時）：
```
1番 走61 ミ56 打力54     4番 打力61 長打59
2番 打力48               5番 長打66
3番 打力57 長打51        9番 打力38（最下位）  8番 投手
```

**打順の変更そのものは得点に影響しなかった**（新旧を同条件で回して打率とも .236）。
打順は誰に打席が多く回るかを変えるだけで、1打席あたりの確率は変えないため。

### ベンチ入り

学年ごとの下駄（1年+10 / 2年+5 / 3年±0）を入れた。

実測（新規開始時のベンチ外4人）：3年 総合34 / 3年 総合38 / 2年 総合33 / 1年 総合14。
ベンチ入りの内訳は 1年7/8・2年7/8・3年6/8 で、**弱い3年生から外れる**ようになった。

## 大会の成長を試合単位にした（2026-08-06）

大会が終わった時点でまとめて配っていたので、
**準決勝で伸びた選手が決勝で活きなかった**。
勝ち上がっている実感も最後の画面まで来ない。

1勝ごとにその場で返す形にした。合計はほぼ変わらない。

| | 変更前（大会の終わりに1回） | 変更後（1勝ごと） |
|---|---|---|
| 式 | (勝ち数 + 0.5 + 優勝なら2) × 格 | (1 + 優勝を決めた試合なら2) × 格 |
| 8勝して優勝 | (8 + 0.5 + 2) = 10.5 | 1×7 + 3 = 10.0 |
| 3勝で敗退 | (3 + 0.5) = 3.5 | 1×3 = 3.0 |

参加ぶんの0.5を落としたぶんだけ僅かに減るが、
**伸びた能力が次の試合で効く**ようになったので、勝ち上がるほど実際に強くなる。

金特の抽選も試合ごとになった。1試合あたりの確率は下がるが、
勝ち上がれば抽選回数が増えるので、通しての期待値は変わらない。

## 成長モデルの作り直し（カード基準へ）

### 何が問題だったか
能力の成長が**練習マスに止まったときだけ**発生していた。
その結果、

- カードで何を選ぶかより「練習マスを踏めるか」で育成が決まる
- カードの数字は移動距離の意味しか持たない（1でも5でも成長は同じ）
- 緑マス・空きマスに止まった手は1ミリも伸びない

という状態になっていた。プレイヤーが毎手行う唯一の選択（カード）が、
いちばん大事な結果（成長）にほとんど効いていない。

### どう変えたか
**カードを成長の土台にした。**

| | 変更前 | 変更後 |
|---|---|---|
| 成長する場面 | 練習マスに止まったときだけ | **毎手（止まったマスに関係なく）** |
| 成長量 | `amount × 0.11` | `amount × 進んだ日数 × 0.0142` |
| 体力の消耗 | `conditionDelta × 0.3` | `conditionDelta × 進んだ日数 × 0.104` |
| マスの役割 | 成長の発生条件 | 倍率の補助（`CELL_GROWTH_BONUS`） |
| 練習効率バフの消費 | 練習マスでのみ | 毎手 |

マスの倍率は 練習1.8 / 青1.2 / 赤0.7 / 緑0.4 / その他1.0。

### 数値の決め方
1年の日数は365で固定なので、**土台の総量は打ち方によらず一定**になる。
そこに平均のマス倍率が掛かる。机上では平均倍率1.30と見積もって
`CARD_GROWTH_SCALE = 0.0115` を置いたが、実測では成長が足りなかった
（6年後の平均総合が 48.3 → 46.3）。

強制ストップ（大会・合宿）や空きマスの比率が効いて、
**実効の平均倍率は1.05前後**だったのが原因。0.0142 まで上げて実測が揃った。

| スケール | 6年後の平均総合 | 年ごとの最高総合（平均） | Aランク/10年 |
|---|---|---|---|
| 0.0115 | 46.3 | 74.1 | 1.5人 |
| 0.0128 | 46.8 | 73.3 | 0.8人 |
| **0.0142** | **48.1** | **75.3** | **2.0人** |
| 0.0155 | 49.4 | 75.5 | 2.2人 |
| （変更前） | 48.3 | 74.3 | 1.7人 |

試合のバランス（打率.264 / 平均3.69-2.90 / 勝率57.5%）は変更前と同一。

### 副次的に直したもの
- **変化球の習得判定**を日数比例（1日5%）にした。
  毎手判定になったぶん、そのままだと1年で全球種を覚えてしまう。
- **1回の練習で「+1」が出ない手が増えた。**
  1日ぶんの伸びは1に満たないので、確率で切り上がるまで名前が挙がらない。
  部員20人ぶんを見れば毎手誰かは伸びるが、
  「1回の練習で個人差が見える」ことは求められなくなった
  （差が出るのは**名前が挙がる頻度**のほう）。

### まだ気になっていること
- 総量が固定なので、**大きい数字を使い続けても年間の成長は変わらない**。
  「5のカードで一気に伸ばす」快感はあるが、長期の最適化としては
  「どのマスに止めるか」だけが残る。ここに物足りなさが出ないかは実プレイで確認したい。
- 休養カードも日数に比例して回復するようにしたので、
  **数字の小さい休養カードがほとんど効かない**。
  体力が切羽詰まったときに1の休養カードしか無い、という詰み方をしないか要検証。

## 投手の値踏みに球速を入れた

`pitcherValue`（先発の選定と継投の順番）が
`control * 0.35 + stamina * 0.3 + breaking * 0.35` で、**球速が1ミリも入っていなかった**。

打席の判定（`simulateAtBat`）は球威に占める球速の比重を 0.7 まで上げてあるのに、
選ぶ側がそれを見ていなかったので食い違っていた。実測では
**初期名簿60件中4件（投手が2人以上いるケース）で最良投手が先発から外れ**、
147km/h・総合74の投手がベンチに座って、142km/hの投手が投げていた。

```
stuffScore = velocityScore(球速) * 0.7 + 変化球 * 0.3   // simulateAtBat と共有
pitcherValue = stuffScore * 0.45 + 制球 * 0.3 + スタミナ * 0.25
```

修正後は60件すべてで最良投手が先発になった。

副次的に勝率がわずかに動く（打率.263 / 平均3.61-2.79 / 勝率56.5%）。
より良い投手が投げるぶん大会を勝ち上がりやすく、
大会成長でAランクが10年あたり2.0人→3.0人に増えている。
過去の実測は1.0〜2.7人なので帯の上限寄りだが、範囲内と判断した。

## 大差での投手交代が一度も起きていなかった

`maybeChangePitcher` は**守備側のチーム**を渡して呼ばれているのに、
`isGarbageTime` が相手を `ctx.defenseTeam` で決め打ちしていた。
守備側を渡すと自分自身と引き算することになり、点差が**常に0**になる。

```ts
// 誤り：team が守備側だと team === ctx.defenseTeam
const diff = team.runs - ctx.defenseTeam.runs   // → 0

// 修正：team から見た相手を ctx から引く
const opponent = team === ctx.offense ? ctx.defenseTeam : ctx.offense
const diff = team.runs - opponent.runs
```

`maybeRestStarter` のほうは攻撃側を渡していたので正しく動いており、
**打線だけ控えに代わって、エースは何点差でも投げ切っていた**。
「同じ場面判断を両方から呼ぶ」ことは守れていたのに、
判定の中身が呼び手の立場に依存していたので片方だけ壊れていた。

投手の疲労が溜まりすぎるという体感の主因はこれ。

## コールドゲームと疲労の調整

| 項目 | 変更前 | 変更後 |
|---|---|---|
| コールド | 無し | **5回10点差 / 7回7点差**（練習試合と地区大会のみ） |
| 完投の疲労 | 60 | **48** |
| 大差の判定開始（リード時） | 7回 | **6回** |

大差の判定開始を早めたのはコールドを入れたため。7回終了・7点差で
打ち切られるので、7回から動き始めると控えに投げさせる回が残らなかった。

実測（balanceCheck）：平均9.06回（コールドのぶん短くなった）／
打率.265／平均3.38-2.97／勝率57.5%。
seasonBalance は6年後の平均総合49.7・Aランク1.8人で、従来の帯の中。

## 投手の入部を毎年2人に

部全体で2人という下限だけだったので、投手が引退した年に
「新入生が全員野手」を引くと立て直せなかった。
**その年の入部（スカウトを含む）で2人**を下限にした（`MIN_PITCHER_RECRUITS`）。
3年生が夏で引退することを考えると、毎年2人入れておかないと
秋の新チームで継投が組めない。

## 練習試合の相手を選べるようにした

止まった瞬間に相手・遠征先・遠征費が決まっていたので、
プレイヤーは**引かれたあとで気づく**しかなかった。断ることもできない。

いまは候補を3つ出し、選んだときに初めて遠征費を引く。

- **県内の候補は必ず1つ入る**（遠征費0）。部費が乏しくても断らずに戦える
- 各候補に **遠征費** と **格の差**（格上／やや格上／互角／やや格下／格下）を出す
- **「試合を行わない」** も選べる
- 払えない候補は表示するが選べない（「行けるが高い」と「足りない」を区別する）

遠征は相手が強くなり（`AWAY_OPPONENT_BONUS = 8`）、評判が+1される。
この2つが遠征する理由になる。

### 部費への影響
無戦略プレイ（`autoPlay`）は**いちばん安い候補＝県内**を選ぶようにした。
そのぶん診断上の遠征費が落ちている（5年で301k/16.2回 → 257k/10.0回。
残りは大会の遠征費）。残高は634k で従来（629k）とほぼ同じ。

**選ばなければ出ていかない**ようになったので、部費の使い道として
グラウンド・器具・スカウトとの取り合いがはっきりした。

## 自動編成に「守備位置ごとの重み」と「同じくらいなら下級生」を入れた

|---|---|

| 右翼 | 0.55 : 0.45 |
| 一塁 | 0.47 : **0.53** |
| 左翼 | 0.43 : **0.57** |

### greedy だけでは足りなかった
守備の重要度順に埋めると、**後回しの一塁・左翼に余り物しか来ない**
（CLAUDE.md「順番に取ると、先に取った枠が得をする」の再発）。
実測で「一塁のほうが遊撃より打つ」のは40例中**5例**しかなかった。

埋め終わってから2人ずつ入れ替えて、総和が増えなくなるまで詰める
（`improveBySwaps`、8枠＝1巡28通り・最大4巡）。20例まで改善した。

位置ごとの「打力の順位」平均（1が最も打つ／8人中、60例）:

| 1B | 2B | 3B | SS | C | LF | RF | CF |
|---|---|---|---|---|---|---|---|
| **3.77** | 4.12 | 4.13 | 4.25 | 4.92 | 4.55 | 4.68 | **5.58** |

一塁がいちばん打ち、中堅がいちばん打たない。外野の中でも 左翼 < 右翼 < 中堅 の順。
**差がこの程度に留まるのは適性の制約による。**
捕手適性の選手を一塁に回すことはできないので、動かせる余地はもともと大きくない。

### 同じくらいなら下級生
`YOUTH_TIEBREAK = 1.5`（1学年あたり）を**スタメンとベンチ入りで共有**する。
1年生と3年生の差は3で、能力3点ぶん。序列をひっくり返す力は持たせない。

ベンチ入りは以前 10/5/0 の下駄だったので、**総合45の1年生が総合54の3年生を
押し出していた**。「僅差なら下級生」であって「下級生なら誰でも」ではないので、
スタメン側と同じ 3/1.5/0 に揃えた。

### 実測
編成が噛み合うぶん勝率が上がる（57.5% → 61.5%）。
平均3.46-2.71／打率.264／平均9.11回。
6年後の平均総合49.1・Aランク2.3人で、従来の帯の中。

## 他校の選手を「実在」させた

相手の9人を戦力値からその場で作って捨てていたので、

- 同じ学校と2回戦っても別人が出てくる
- スカウトで逃した選手がその学校に居ない
- 誰と戦っているのか分からないまま試合が始まる

という状態だった。かといって30校×15人を保存するとセーブが膨らむ。

**保存する代わりに、種から毎回同じ名簿を作る。**
学校が持つのは `rosterSeed` という数値ひとつだけ（`rivalRoster`）。

- **入学年ごとに種を分ける。** 今年の1年生は来年も同じ名前の2年生として出てくる
- 3年生は翌年の名簿から消える（卒業）
- 能力はその学校の今の戦力（`strength`）が基準。学校が力をつければ在校生も強く見える
- 注目選手（スカウトで逃した選手・U18候補）は、**同学年のいちばん弱い選手と入れ替えて**名簿に混ぜる。
  足すと部員数が増えて有利になり、いちばん強い選手を押しのけると学校の格が下がる

### つまずいた点
名前の重複避けを3学年ぶんまとめて行っていたら、
**「その年に居合わせた他学年」によって名前が変わり**、
今年の1年生が来年は別人になっていた。
重複避けは学年の中だけで行う（学年をまたいだ同姓同名は 120×120 の名前から選ぶので滅多に起きない）。

### 入部の経路
`Player.origin`（`scout` / `recommended` / 省略＝一般入部）を足した。
出張費を払って通った相手が、入部後は他の新入生と見分けが付かなかった。
逃した選手のほうも、進学先の名簿で「スカウト」の印が付く。

**会いに行った選手は素質を問わず他校に残す**ようにした（以前は素質56以上だけ）。
通っていた相手が翌年どこにも居ないのでは張り合いが無い。

## 投手の人数を固定した

`MIN_PITCHER_RECRUITS`（下限）を `PITCHER_RECRUITS`（固定2人）に変えた。
下限＋抽選だったので、確約したぶんの上に抽選ぶんが積み上がり、
**投手ばかり5人入ってきて野手が薄くなる年**があった。
`isPitcher` に `undefined`（抽選）を渡さず、true/false を必ず決める。

ベンチ入りには投手を**必ず3人**入れる（`MIN_SQUAD_PITCHERS`）。
総合だけで並べると投手が押し出され、大会で継投が組めなくなる。

## 評判が30で頭打ちになり、県内に格上が居なくなる

### 実測した症状（無戦略プレイ・勝率6割）
| 年 | 評判 | 自校スタメン平均 | 県内10校の格 |
|---|---|---|---|
| 1 | 20 (F) | 57 | 格上1 互角2 格下7 |
| 7 | 30 (E) | 60 | 格上3 互角0 格下7 |
| 10 | 29 (E) | 67 | **格上0 互角0 格下10** |

「中堅以下（E）から上がらない」「みんな格下」という体感どおりだった。原因は3つ。

### 原因1：上がりにくさが効きすぎ（2乗）
`raw × room²` は、釣り合いに必要な勝敗比が

| 評判 | +1の通り | -1の通り | 釣り合う勝敗比 |
|---|---|---|---|
| 30 | 0.49 | 0.30 | 0.6 : 1 |
| 50 | 0.25 | 0.50 | **2.0 : 1** |
| 64 | 0.13 | 0.64 | **4.9 : 1** |

勝率6割では50を超えられない。指数を **1.5乗** に緩めた（50で0.35、64で0.22）。

### 原因2：大会の評判が「優勝」だけ
`reputationGain` は `champion` でなければ **0** を返していた。
決勝で負けた年と初戦で負けた年が同じ扱いで、
県大会でベスト4に入り続けても評判が動かなかった。

勝ち上がった割合に応じて出すようにした（決勝進出で優勝の約半分、`RUNNER_UP_SHARE = 0.55`）。
「勝ち切ること」の価値は残してある。

### 原因3：県内に名門校が居ない
地力の分布が **県内 最高16 / 県外 最高34** で、
3年も育てれば県内の全校が格下になっていた。

県内にも名門校（地力24〜33）と2番手（14〜24）を置いた。
甲子園常連が県外にしか居ないのでは、「県内に倒すべき壁がある」手応えが出ない。

### 直したあと
| 年 | 評判 | 県内10校の格 |
|---|---|---|
| 1 | 20 (F) | 格上2 互角2 格下6 |
| 7 | 40 (D) | 格上2 互角1 格下7 |
| 12 | 37 (D) | 格上1 互角2 格下7 |

長期（72年）でも 36〜45（D 中堅校）で安定。試合バランスは変わらず
（打率.263／3.49-2.63／勝率62.5%）。

**なお勝率6割では D 止まりが妥当**と判断した。
B（強豪校・64）以上は県大会を勝ち抜き続けるチームの位置づけで、
無戦略プレイで届いてしまうと評判を上げる意味が無くなる。

## 「優勝しても評判が上がらない」の正体は整数丸めだった

`applyReputation` が `Math.round` で**整数に丸めて保存**していた。

| 評判 | 1勝の素の値 | 通る量 | 保存されると |
|---|---|---|---|
| 20 | +1 | 0.72 | **+1**（残る） |
| 40 | +1 | 0.47 | **±0**（消える） |
| 40 | -2.15（格下に負け） | -0.86 | **-1**（残る） |

**勝ちの加算だけが毎回切り捨てられ、負けだけが残っていた。**
負けの素の値は格下相手だと -2 を超えるので丸めを生き延びる。
評判が上がるほど勝ちが消えるので、40前後で完全に止まる。

大会の優勝ボーナス（秋季5・夏12）も、
6試合ぶんの勝ちが全部消えたうえに単発で足されるだけなので、
「優勝したのに数字が動かない」ように見えていた。

**積み上げる値を表示の桁で丸めてはいけない。**
小数第1位まで保ち、表示のときだけ `reputationDisplay` で整数にする。

### 直したあと（無戦略プレイ・勝率6割）
```
seed 501: 20F → 23F → 30E → 35E → 37D → 38D → 40D → 45D → 51C → 50D → 45D → 51C
seed 777: 20F → 22F → 26E → 33E → 32E → 37D → 32E → 37D → 41D → 41D → 48D → 51C
```
長期（72年）では 42〜64（C〜B）を行き来する。
評判が上がったぶん良い新入生が来るので、平均総合も 49 → 52〜59 に上がった。
試合バランス（打率.263／3.49-2.63／勝率62.5%）は変わらない。

## 強豪校（B・64）が実質到達不可能だった

### 症状
評判64を保つのに、**格下相手で85〜95%の勝率**が必要だった。

| 相手との差 | 評判30 | 評判50 | 評判64(B) | 評判78(A) |
|---|---|---|---|---|
| 5点下 | 45% | 67% | **85%** | 93% |
| 10点下 | 60% | 78% | **90%** | 96% |
| 20点下 | 73% | 87% | **95%** | 98% |

### 原因：強くなるほど評判が上がりにくくなっていた
チームが育つほど相手との差が開く。ところが

- 勝ち … 格下相手は**ずっと +1**（`WIN_BASE`）
- 負け … 差に比例して膨らみ、**最大 -5.4**（`COLLAPSE_RATE = 0.25`、上限なし）

なので、**強くなるほど1敗の代償だけが増えていく**という逆転が起きていた。
そこへ加算側の鈍り（評判64で0.216倍）が重なる。

### 直したこと
| | 変更前 | 変更後 |
|---|---|---|
| 格下に負けた上乗せ | 0.25/点 | **0.10/点** |
| 1敗の上限 | 無し | **-2.5** |
| 加算の鈍り（指数） | 1.5 | **1.35** |

必要な勝率（10点下の相手）：評判64で 90% → **約77%**。

### 指数の決め方
| 指数 | 無戦略プレイ（20年） | 能力+10のチーム（20年） |
|---|---|---|
| 1.5 | 51C 止まり | — |
| **1.35** | **59C** | **90S** |
| 1.2 | 83A（緩すぎ） | 95S |

**無戦略でAに届いてしまうと評判を上げる意味が無くなる。**
1.35 なら、放っておけばC（有力校）で頭打ち、
育てて県大会を勝ち抜けるようになればB→Aと伸びる。

### 副次的な変更
1敗の上限を入れたことで、**格上を倒したときの上がり幅（最大+7）が
格下に負けた下がり幅（-2.5）を上回った**。
「挑んで勝つことが評判の主な稼ぎ」という形になったので、
`番狂わせの上がり幅は格下に負けた下がり幅より小さい` というテストは
意図を書き換えて差し替えた。
