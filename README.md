# ハイスクール・ナイン（仮称）

スマホ縦画面・片手操作で遊べる、高校野球部の育成シミュレーションゲーム。
「練習カードを選ぶ → マス目を進む → イベントで成長 → 大会に挑む → 世代交代」を無限に繰り返す、周回型の育成ゲームです。

> 本作は市販タイトルのオマージュであり、実在の球団名・大会名・選手名・ロゴ等は使用しません。すべて独自の名称・データを用います。

---

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| ジャンル | 高校野球 育成シミュレーション |
| プラットフォーム | Web（PWA想定）／スマホブラウザ優先 |
| 画面 | 縦画面固定（9:16〜9:21）、片手操作、タップ中心 |
| 1プレイの単位 | 1ヶ月（カード選択1回＝マス移動1回）で数十秒 |
| ループの長さ | 1年＝12ヶ月、1世代＝3年、以降は無限ループ |
| セーブ | ブラウザ localStorage への自動セーブ（1スロット＋バックアップ） |

### 遊びの核
1. **選択の緊張感** — 手札5枚から1枚。数字（進むマス数）と練習内容のどちらを取るか。
2. **積み重ねの実感** — 能力値・信頼度が数字で伸びていく手応え。
3. **大会での回収** — 3年間の育成結果が、完全自動の試合で答え合わせされる。操作はしない。
4. **世代交代の切なさ** — 育てた3年生は必ず引退し、新入生が入ってくる。

## 3. 主要システム

### 3.1 練習カード
- 毎月、手札を **5枚** 配る。1枚選ぶと残りは捨てられる。
- カードは `数字（1〜5）` × `練習種別` の組み合わせ。
- 数字＝すごろくで進むマス数。数字が大きいほど遠くのマスに届くが、通過マスのイベントは（原則）発生しない。
- カードは全**24種類**（うち6種類は練習器具を買うと出るようになる）。練習だけでなく、部の運営に効くカードも混ざる。

| 分類 | 種別 |
|---|---|
| 打撃 | 打撃練習 / バント練習 / 打ち込み |
| 走塁 | 走塁練習 / ダッシュ / 走り込み |
| 守備 | 守備練習 / 遠投 |
| 投手 | 投球練習 / 変化球練習 / 制球練習 |
| 心身 | メンタル強化 / 休養 / 息抜き |
| 運営 | ミーティング（やる気+1） / グラウンド整備（設備+1） / 治療（離脱-1ヶ月） / 自主学習（信頼度+9） |
| 器具 | ティー打撃 / ウエイト / アジリティ / マシン打撃 / ブルペン投球 / ビデオ分析 |

能力を伸ばすだけのカードばかりだと選択が単調になるので、
**やる気・設備・怪我といった別の軸に効く**カードを混ぜている。

**器具の6種類は最初は手札に出ない。** ショップで練習器具を買うと出るようになる（後述）。
- レアカード（キラカード）：効果2倍・全体練習など。低確率で出現。

### 3.2 マス目（すごろく）
**1マス＝1日、盤面は1年で1本（365マス）。**
4月1日から3月31日まで途切れずに道が続き、月ごとのゴールは無い。
月は「何日目か」から決まるので、進むうちに自然に変わっていく。
本家の色分けを踏襲している。

| 表示 | 種別 | 効果 |
|---|---|---|
| 練 | `practice` | 選んだカードの練習内容で全員が成長 |
| 青 | `good` | 良いイベント（大成長／信頼度／やる気／特別指導） |
| 赤 | `bad` | 悪いイベント（能力ダウン／やる気ダウン／消耗） |
| 白 | `random` | 良いことも悪いことも起こる |
| 緑 | `rest` | 体力が大きく回復 |
| 黄 | `boost` | **練習効率アップ**（次の練習が1.5〜2.5倍） |
| 特 | `training` | **特訓**。選手1人が特殊能力の取得に挑戦 |
| OB | `alumni` | 卒業生が訪問し、3人が指導を受ける |
| 試 | `match` | 練習試合。勝敗で信頼度が変わる |
| 分 | `fork` | **ルート分岐**。この先30日ぶんの傾向を選ぶ |
| 大会 | `tournament` | **大会。必ず止まる**（飛び越えられない）。1回戦ごとに1マス |
| 合宿 | `camp` | **冬合宿。必ず止まる** |
| ・ | `blank` | 何も起きない日 |
| 年度末 | `goal` | 3月31日 |

**黄マス→練習マスの繋ぎ**が最も効率が良い。練習効率バフは練習マスでのみ消費されるため、
「どのマスに止めるか」を数字で読む駆け引きが生まれる。

#### マスの密度は「1年に何回あってほしいか」で決める
1マス1日にすると1年の手数が約146手になる。重みをそのままにすると、
**練習試合も特訓も怪我も年3倍**起きてしまう。
そこで練習マス以外は年あたりの回数から逆算して薄め、増えたぶんは
練習マスと空きマスが受け持っている。

| マス | 重み | 年あたり（146手） |
|---|---|---|
| 練習 | 42 | 61 |
| 何も無い | 28 | 41 |
| 休養 | 5 | 7.3 |
| 青・赤・白・黄 | 各4 | 各5.8 |
| 練習試合 | 3 | 4.4 |
| 特訓・OB・分岐 | 各2 | 各2.9 |

#### 日付と大会マス
| 日付 | 出来事 |
|---|---|
| 7月15日 | 夏の地区大会 |
| 8月12日 | 夏の全国大会（出場権があるときだけ盤面に現れる） |
| 10月15日 | 秋季地区大会 |
| 12月26日 | 冬合宿 |
| 3月10日 | 春の全国大会（出場権があるときだけ） |

- 大会・合宿のマスは**通り過ぎられない**。カードの数字が足りていても手前で止まる。
- 地区大会に優勝すると、**全国大会のマスがその場で盤面に立つ**。
- 出場権は年度をまたぐと失効し、翌年の盤面には置かれない。

#### 大会は1回戦ずつマスに並ぶ
大会は連戦ではない。開幕日のマスに1回戦、そこから**中1日（2マス）先に2回戦**……と、
参加校数から決まる回戦ぶんのマスが盤面に並ぶ（`placeTournamentCells`）。

- 1つ勝つと盤面に戻り、次の回戦のマスまでは**普通に練習できる**。
  勝った直後に「次は◯回戦。◯月◯日に行われる」と告知が出る。
- 敗退（または優勝）すると、`clearTournamentCells()` で**残りの回戦のマスが消える**。
- 春の全国大会だけは実際より少し早い3月10日に置いている。実際の日程だと
  8回戦ぶんのマス（中1日で15日）が年度末（3月31日）を越えてしまうため。

> 連戦式だった頃は、大会マスに止まると優勝か敗退まで戻ってこられなかった。
> 「勝ち進むほど盤面が進まない」ので、強いチームほど1年の練習回数が減るという
> 逆転が起きていた。回戦をマスに割ると、勝ち進むこと自体が盤面を消費する。

#### カードの数字＝進むマス数（＝日数）
数字は **1〜5**（平均2.5日）。1年をおよそ146手で回る。

> ここを大きくすると1年の手数が減り、練習回数が減って**成長が一気に遅くなる**。
> 逆に小さくすると手数が増えて速くなる。
> **手数を変えたら1手あたりの効果も割り戻すこと**
> （`PRACTICE_GROWTH_SCALE` / `CARD_COST_SCALE`）。
> 変えるときは必ず `seasonBalance.test.ts` を回すこと。

#### ルート分岐（分マス）
止まると3つの道筋から1つを選び、**その先のマスが選んだ方針で作り直される**。

道筋は基本の盤面（練習42% / 空き28%）より特別なマスを厚くしてある。
だからこそ分岐マスに止まる価値がある。

| 道筋 | 傾向 |
|---|---|
| 練習の道 | 練習70% / 黄10%。堅実に伸ばす |
| 挑戦の道 | 特訓8% / OB6% / 試合7%。ただし赤12%（基本の3倍） |
| 休養の道 | 緑25% / 練習35%。赤はわずか3% |

作り直すのは**この先30マス（＝30日）だけ**。1年まるごと書き換えると1回の選択が効きすぎて、
以降の判断が意味を失う。大会・合宿・年度末のマスは動かさない。

盤面が固定の運任せではなくなり、**チームの状態に応じて方針を選べる**。

### 3.2.1 特殊能力
金（強力）／青（有利）／赤（不利）の3ランク。主に**特訓マス**で習得する。
- 金特は**信頼度60以上**の選手だけが挑戦でき、成功率も低い（育成の目標になる）
- 赤特（マイナス能力）は青マスの「特別指導」で消せる
- 名称はすべて独自のもの（実在作品の名称は使わない）

### 3.2.2 部員数とベンチ入り

初期部員は **各学年8人（計24人）**。評判が上がると新入生は最大16人まで増え、
強豪校では40人規模になる。

弱小校のうちは二軍が組めるほどの規模ではないので、扱うのは
**ベンチ入りできるかどうか**だけにしている。

- **ベンチ入り（20人）はプレイヤーが決める**（スタメン画面でドラッグ）。
  自動で総合上位を選んでいた頃は、伸ばしたい下級生をベンチに入れられなかった。
  新規ゲームと、部員が入れ替わって枠が空いたときだけ総合上位で埋める。
- ベンチ外も練習には参加するが、**伸びは75%**。
- **試合に連れて行けるのはベンチ入りの選手だけ。** 代打・継投もここからしか出せない。
- 離脱中の選手はベンチの枠を占有しない（控えが繰り上がる）。

「全員を等しく育てられるわけではない」という規模の実感を出すための仕組み。

### 3.3 選手データ
**野手能力**：弾道(1-4) / ミート / パワー / 走力 / 肩力 / 守備 / 捕球（各 1-100、表示はF〜S）
**投手能力**：球速(km/h) / コントロール / スタミナ / 変化球（総合力）＋ **持ち球**
**共通**：ポジション適性、特殊能力、やる気（絶不調〜絶好調の5段階）、信頼度（0-100）、体力、怪我状態、学年（1-3）、性格

#### 性格（6種）
表示だけでなく、成長と試合の両方に効く。**どれが強いかではなく、得意分野が違う。**

| 性格 | 効果 |
|---|---|
| ど根性 | 体力が低くてもペナルティが半分。土壇場に強い |
| クール | やる気の影響が半分。四球を選びやすくプレッシャーに強い |
| ムードメーカー | 信頼度が1.6倍上がりやすい |
| したたか | 四球を選びやすく、体力消費が15%少ない |
| 天才肌 | **出現率2%のレア性格。** 入学時の能力が +8、成長 +40%。ただしやる気の影響が1.5倍 |
| やんちゃ | 成長 +12%。ただし体力消費が30%多い |

**天才肌だけは狙って手に入らない。** 6分の1で出ていた頃は
どの学年にも数人いて、いちばん伸びる性格が当たり前に手に入っていた。
2%まで下げたぶん、入学時点の能力も成長も別格にしてある。
引き当てた学年が特別に感じられないと、レアにした意味が無い。

- **信頼度** が高いほどイベント発生率・試合での能力補正が有利になる。
- **やる気** は月ごとに変動し、練習効率と試合パフォーマンスに直結。

#### 伸びやすい能力は選手ごとに違う
選手は**得意な能力2つ・苦手な能力2つ**を持つ（`growthAptitude`）。

| | 倍率 |
|---|---|
| 得意 | 1.25〜1.6 |
| 標準 | 1.0 |
| 苦手 | 0.6〜0.8 |

平均が1.0前後になるよう配分してあるので、**チーム全体の成長速度は変わらない**。
変わるのは「誰のどの能力が伸びるか」だけ。選手詳細の見出しに「得意 捕球・守備／
苦手 走力・肩力」と出る。

> これが無いと、**1回の練習で全員が同じだけ伸びる**。
> やる気・学年・体力の補正は前からあったが、1回の伸びが1〜2という小さな値なので
> 整数に丸めた時点で差が消え、画面には誰を見ても「+1」しか出てこなかった。
> 苦手を0.5まで下げると今度は事実上凍りついて総合が伸び残るので、
> 「遅い」であって「動かない」ではない水準（0.6）で止めてある。

**ポジション適性**：全9ポジションに S〜G の適性を持つ。本職は S。
適性が低い位置で起用すると守備力に補正がかかる（S=1.0倍 … G=0.3倍）。

#### ポジションごとの守備の重み

守備力は均等平均ではなく**位置の重要度で重み付けする**。
均等だと遊撃に守れない選手を置いても一塁の名手で帳消しになり、
適性を気にする理由が無くなってしまう。

| 位置 | 遊撃 | 二塁 | 捕手 | 中堅 | 三塁 | 右翼 | 一塁 | 左翼 | 投手 |
|---|---|---|---|---|---|---|---|---|---|
| 重み | 1.00 | 0.92 | 0.85 | 0.78 | 0.62 | 0.50 | 0.36 | 0.30 | 0.20 |

適性 C より下の位置で起用すると、守備力の低下とは**別に**
失策率と被安打率が上がる（重要な位置ほど大きい）。
自動編成もこの順で埋めるので、良い守り手はまず二遊間と捕手に入る。

#### 選手データ画面（4タブ）
部員一覧・スタメンから選手をタップすると開く。情報量が多いのでタブで分ける。

| タブ | 内容 |
|---|---|
| 能力 | 投手能力（球速・コントロール・スタミナ・変化球）＋**持ち球の変化方向図** → 野手能力（弾道・ミート・パワー・走力・肩力・守備・捕球）。各行にランク・ゲージ・実数値を並べる。下にやる気／体力／信頼度／怪我 |
| 特殊能力 | 金特（強力）／青特（有利）／赤特（不利）に分けて、**効果の説明つき**で表示。未習得なら習得手段を案内する |
| 成績 | **高校での通算成績**（後述）。U18代表歴があればここに出る |
| 成長 | **入学時からの推移を項目ごとの折れ線グラフで表示**（後述） |
| 起用 | ポジション適性の一覧とコンバート |

投手は投手能力を先に出す。野手には投手能力の欄自体を出さない。

#### 能力の推移グラフ
`Player.history` に**月が変わるたび**その時点の能力を1件ずつ記録する
（`AbilitySnapshot`。上限 `HISTORY_LIMIT = 44` 件 ≒ 3年10ヶ月ぶん）。

- 1項目 = 1グラフの **small multiples**。9項目を1枚に重ねると線が混ざって読めないため。
- 縦軸は全項目 **1〜100 で固定**。項目どうしの高さを比べられるようにするため
  （球速だけ km/h なので 110〜165）。
- 単一系列なので凡例は置かない。見出しが系列名を兼ねる。
- 点ごとの数字は出さず、**触れた位置の値を読み取る**方式（スマホで潰れないため）。
- 見出しの右に「現在値」と「入学時からの増減」を出す。
- 履歴の末尾に現在値を足して描くので、能力タブの数字と必ず一致する。

#### 持ち球（変化球の球種）
「変化球 D」という数字だけでは、その投手が何を投げるのか分からない。
**方向ごとに複数の球種**を用意し、どれを覚えるかを選手ごとに変えることで、
同じ変化球の値でも投手の個性が出るようにした。

| 方向 | 球種の例 |
|---|---|
| スライダー系（左） | スライダー / カットボール / 高速スライダー / スラーブ |
| カーブ系（左下） | カーブ / スローカーブ / ナックルカーブ / ドロップカーブ |
| フォーク系（下） | フォーク / SFF / チェンジアップ / パーム / スプリット |
| シンカー系（右下） | シンカー / サークルチェンジ / スクリュー / Vスライダー |
| シュート系（右） | シュート / ムービングファスト / ツーシーム |
| 特殊（上） | ナックル / ホップライジング |

- 同じ方向に2つは持てない。変化量は1〜7。
- **変化球練習で35%の確率**で新球種を覚えるか、変化量が1上がる。
  持ち球の数は変化球の総合力に見合った数（40未満で1、70未満で2、70以上で3）まで増える。
- 試合の判定に使うのは従来どおり `breaking`（総合力）。球種は「何を投げる投手か」を見せるもの。
- 選手データ画面に**中心から各方向へ矢印を伸ばした図**で表示する（`PitchChart`）。

#### 選手ごとの練習方針
チーム全体の練習カードだけだと「この選手のミートだけ伸ばしたい」という意図が通らない。
選手データの**練習タブ**から、選手ごとに自主練の内容を**いつでも**指定できる。

| 方針 | 効果 |
|---|---|
| チーム練習に合わせる（既定） | すべての能力が等倍で伸びる |
| 能力を1つ指定 | その能力は**1.6倍**、それ以外は**0.6倍**。チームの練習に含まれない能力でも少しずつ伸びる |
| コンバート | 通常の練習の伸びが**0.7倍**になる代わりに、守備適性が上がっていく |

**絞るほど他が伸びにくい**というトレードオフを置いている。
全員を自由に伸ばせては、誰をどう育てるかの判断が消えるため。

#### コンバート（練習で覚える）
以前は部費で1段階ずつ買っていたが、**守る位置は金ではなく練習で覚えるもの**なので
練習方針に移した。

- 練習**8回**で適性が1段階上がる。**A まで**（本職Sには届かない）。
- 方針を変えると進捗はやり直しになる。
- 離脱中（怪我）は進まない。
- A に届くと自動でチーム練習へ戻る。
- 部員一覧・スタメンのカードにも「SSへ転向」のように表示される。

#### ネームプレート（ポジションで色分け）
選手名の背景を**本職の系統の色**で塗る。他に守れる位置があれば、その色が右へ混ざる。
一覧を眺めるだけで「どこを守れる選手か」が色の帯で読める。

| 系統 | 色 |
|---|---|
| 投手 | ピンク |
| 捕手 | 水色 |
| 内野（1B/2B/3B/SS） | 黄 |
| 外野（LF/CF/RF） | 緑 |

- **左が本職**の色。適性C以上の位置があれば、その系統の色が右側に入る。
- 例：中堅手（緑）で遊撃も守れる（黄）なら、左が緑・右が黄のプレートになる。
- 色だけでは何色が何か伝わらないので、スタメン画面に凡例を置く。

### 3.3.1 スタメンとベンチ入りの編成
打順9人と守備位置、それに**ベンチ入り**をこの画面で決める。
高校野球なので指名打者は無く、投手も打席に立つ。

3つの列（スタメン／ベンチ入り／ベンチ外）を**指でつまんで入れ替える**。

| 操作 | 結果 |
|---|---|
| スタメン → スタメン | 打順を入れ替える |
| ベンチ → スタメン | 出場させる。押し出された選手はベンチ入りへ |
| ベンチ外 → ベンチ入り | ベンチに入れる（定員20人。埋まっていれば末尾と交換） |
| ベンチ入り → ベンチ外 | ベンチから外す |
| （自動） | スタメンの選手は必ずベンチ入りに含まれる |
| プレートをタップ | 右側にその選手の能力を表示 |
| 守備位置ボタンをタップ | 守備位置を選び直す |

- スタメンの選手は列から外せない。**誰かと入れ替える形でしか動かせない**
  （抜けると9人揃わなくなるため）。
- ベンチから外したぶんは**自動で補充しない**。補充すると、外した選手が
  「いちばん強い控え」としてその場で戻ってきて入れ替えができない。
  補充するのは年度替わりと新規ゲームだけ。
- ドラッグは HTML5 の drag&drop ではなく**ポインタイベントで自前に実装**している。
  HTML5 のほうはタッチ端末で動かないため。
- **掴むのは行の左端の ⠿ だけ。** 行全体を掴めるようにしていた頃は、
  行に `touch-action: none` が乗るせいで**その上ではページがスクロールできなかった**
  （見出し付近しか反応せず、実質操作不能だった）。つまみ以外の場所は普通にスクロールする。
- 縦画面なので本家のように4列を横に並べるのは諦め、列は縦に積んで
  能力パネルだけ右側に固定している。
- 部員が抜けて編成が崩れた場合は自動で組み直される

#### おまかせ編成は3方針から選ぶ
どの位置から埋めるかは共通で、代わりの利かない位置（投手→遊撃→二塁→捕手→中堅…）から
順に埋め、そのあと打順を組む（1番=走力、2番=ミート、3-4番=打力、投手は最後）。
違うのは**各位置に誰を入れたいかの評価軸**（`fitFor`）。

| 方針 | 評価 | 向く場面 |
|---|---|---|
| バランス | 守備適性0.7 ＋ 打力0.3 | 既定。守れる人を守れる位置に置く |
| 能力優先 | 総合1.2 ＋ 守備適性0.5 | 勝ちに行く。適性を多少犠牲にしても強い選手を並べる |
| 若手優先 | 守備適性0.7 ＋ 打力0.3 ＋ 学年ボーナス（1年+44 / 2年+22） | 育てながら戦う。秋以降を見据えるとき |

投手枠には `pitching` を持つ選手しか入れない。野手を投げさせない。

> 単一のロジックだった頃は「3年生の主力が抜けた直後に組み直すと、
> 育てたい下級生が全員ベンチに落ちる」といった噛み合わなさが起きていた。
> どう組みたいかは局面で変わるので、プレイヤーに選ばせる。

#### 部員一覧・スタメンのカード表示
横長の1行では能力を並べる幅が足りず、結局タップしないと分からなかった。
**四角いカードを2列**に並べ、上段に名前・学年・やる気・体力、
下段に**守備適性（グラウンド図）と能力（六角レーダー）**を左右に置く。

- `AptitudeDiamond` … 9つの適性を実際の守備位置に配置する。
  外野型か内野型かが形で読める。本職は金色の丸で囲む。
- `AbilityRadar` … 6軸のレーダー。投手は球速／制球／変化／スタミナ／守備／打撃、
  野手はミート／パワー／走力／肩力／守備／捕球。能力が伸びると形が広がる。
- スタメンでは「適性 A」と**言葉を添える**。ランクだけ置くと総合評価と取り違えられる。
- カード全体をボタンにすると中のボタンと入れ子になり不正なHTMLになるので、
  「交代」「守備位置」はカード内の個別ボタンにしている。

### 3.4 試合（完全自動・観戦型）
**試合中のプレイヤー操作は一切ない。** 采配指示は実装しない。
理由：操作が煩雑になり、テンポを損なうため。プレイヤーの意思決定は育成パート（カード選択）に集約する。

- 試合結果は「投手能力 vs 打者能力 ＋ 状況補正 ＋ 乱数」で1打席ずつ判定。
- **判定ロジックは表示速度と完全に独立**させる。先に試合全体をシミュレートして結果データを作り、それを指定速度で再生するだけにする。
  これにより、どの速度で見ても結果は同一になる（速度で有利不利が出ない）。

```
startMatchState(setup) → MatchState
        ↓ stepHalfInning() を半回ずつ           ← ここに交代を挟める
finalizeMatch(MatchState) → MatchResult（全打席の記録）
                          ↓
              UI が速度に応じて再生するだけ
```

**試合は半回ずつ進む。** 回の切れ目で状態（`MatchState`）を返すので、
そこにプレイヤーの選手交代を挟める。交代を挟まなければ、
乱数の並びは変わらないので**どの速度で見ても結果は完全に同じ**になる。

#### 試合前のスタメン確認
**試合はマスに止まった時点ではまだ行われない。** まず確認画面が出て、
相手校名を見ながらスタメンを組み替えられる。「試合開始」を押して初めて
シミュレートするので、**ここで変えた編成がそのまま結果に反映される**。

- 練習試合も大会も同じ画面を通る。
- 編成が成立していない（守れない位置がある等）ときは開始できない。
- 相手校名は確認画面を出す時点で決めておき、そのまま試合で使う。

#### 投手のスタミナと継投

**スタミナDで約5回**が基準。切れてからも投げ続けられるが、
球威も制球も落ちるので失点が増える。

| スタミナ | G(20) | E(40) | D(55) | C(65) | B(75) | S(90) |
|---|---|---|---|---|---|---|
| 平均投球回 | 1.7 | 4.1 | 5.7 | 6.7 | 7.8 | 8.9 |
| 完投率 | 0% | 0% | 0% | 0% | 13% | 66% |

（`staminaCheck.test.ts`、120試合の実測。以前は D でも7回持ち、
交代の判定も緩かったので毎試合ほぼ完投していた）

#### 選手交代

自動と手動の両方がある。

- **自動**：スタミナが切れた投手を降ろす。7回以降の競った場面で、
  打力がはっきり上の控えがいれば代打を送る。
  ただし**投手の打順には代打を送らない**（守備位置の玉突きが起きて
  誰がどこを守っているか追えなくなるため）。
- **自動（大差）**：7点以上開いたら控えの下級生を出して経験を積ませる。
  リードしているときは7回から、負けているときは5回から
  （勝っている試合で早々に主力を下げると追いつかれかねない）。
  重要な位置ほど守備適性に厳しく、遊撃はD、左翼ならEまで許す。
- **手動**：観戦中に「交代」ボタンでいつでも開ける。押すと進行が止まり、
  打順の枠と控えを選んで入れ替える。スキップ観戦中は出さない。
- **一度退いた選手は戻れない**（高校野球と同じ）。
- 投手の枠には投手能力を持つ選手しか入れられない。
- 手動の交代は**この試合限り**。登録スタメンは書き換えない
  （自動で出た代打まで登録を書き換えてしまうため）。

#### 観戦速度（プレイヤーが試合前に選択）

| モード | 挙動 |
|---|---|
| **スキップ** | 再生なし。最終スコアと要点（決勝打・好投など）のみ即表示。**この試合限りで、設定としては保存しない** |
| **通常** | 1打席ずつアニメーション＋実況ログ。演出あり |
| **高速** | 1打席の表示を短縮し、イニング単位でまとめて流す |

- 速度設定（通常／高速）は保存し、次の試合でも引き継ぐ。
  **スキップだけは保存しない。** 覚えてしまうと、一度スキップしたあと全試合が飛んでしまう。
- どのモードでも試合中に**画面下部のボタンでいつでも切り替え可能**（「スキップ」ボタンは常時表示）。
- 試合後は必ず結果サマリー（スコアボード・個人成績・活躍選手）を表示する。

#### 画面
スコアボードの下に**ダイヤモンド**を表示し、走者のいる塁が光る。アウトカウントも並ぶ。
安打では打球が飛び、得点時は画面が一瞬明るくなる。

#### 実装したルール
- 9回制。同点なら延長12回まで行い、決着しなければ引き分け。
- **プレイヤーは常に後攻**。9回裏以降にリードすればサヨナラでその場で終了し、
  逆にリードして9回表を終えた場合は裏の攻撃を行わない。
- 投手はスタミナに応じて消耗し、限界を超えると能力が落ちて控え投手に交代する。
- 走者が一塁にいて二塁が空いていれば**盗塁**を仕掛ける。走力と**捕手の肩**で成否が決まる。
- 守備力は**スタメンのポジション適性**から計算する（適性外で守ると失策・被安打が増える）。
- 特殊能力は状況によって発動する（得点圏で「勝負師」、走者を背負って「ピンチに強い」など）。
- 試合結果の反映（信頼度・体力）は**観戦を終えた時点**で行う。
  観戦中に反映すると、途中で離脱したときに二重適用される恐れがあるため。

### 3.4.1 大会

**所在地（地区）によって参加校数が違い、それがそのまま回戦数になる。**
これが本作の実質的な難易度選択で、ゲーム開始時に選ぶ。

#### 大会の一覧

| 大会 | 月 | 出場条件 | 規模 |
|---|---|---|---|
| 夏の地区大会 | 7月 | 常に出場 | 地区の参加校数（5〜8勝） |
| 夏の全国大会 | 8月 | 夏の地区大会で優勝 | 49校（6勝） |
| 秋季地区大会 | 10月 | 常に出場 | 地区の約1/3 |
| 春の全国大会 | 3月 | 秋季大会で優勝 | 32校（5勝） |

3月は**春の全国大会 → 世代交代**の順で処理される。

| 地区の例 | 参加校数 | 全国へ行くのに必要な勝ち数 |
|---|---|---|
| 神奈川 | 178校 | **8勝** |
| 福岡 | 130校 | 8勝 |
| 宮城 | 66校 | 7勝 |
| 島根 | 38校 | 6勝 |
| 鳥取 | 24校 | **5勝** |

- 回戦数は `ceil(log2(参加校数))` で求める。
- 参加校が多い地区は**相手も強い**（`regionStrength`）。道のりが長いだけでなく、質も高い。
- 北海道と東京は南北・東西に分かれるため、地区は全部で **49**。全国大会はこの49校で戦う（6回戦）。
- 校数は実際の規模を参考にした**概数**で、ゲームバランス用の値（正確な統計ではない）。

#### 大会のルール
- 1回戦は格下、決勝は格上と、**勝ち進むほど相手が強くなる**。
- 大会の相手は**こちらの実力に追従させない**。練習試合と違い、
  大会は「育成が足りていたか」を測る場なので難易度は絶対値で固定する。
- **引き分けは無い。** 10回からタイブレーク（無死一・二塁開始）で必ず決着をつける。
- 評判は**1試合ごとに動く**（後述）。優勝したときだけ、それとは別に大きな加算がある。

### 3.4.2 冬合宿

12月に入ると1度だけ発生し、**強化方針を1つ選ぶ**。

| 方針 | 効果 | 体力 |
|---|---|---|
| 打ち込み | ミート・パワー | -30 |
| ノック漬け | 守備・捕球 | -28 |
| 投手強化 | 投手のコントロール・スタミナ | -26 |
| 走り込み | スタミナ・走力 | -40 |
| 精神統一 | 信頼度が大きく上がる | -12 |

- 通常の練習およそ**5回ぶん**がまとめて入る。
- 合宿後は練習効率バフ（1.5倍×3回）が残る。
- 年に1度、チームの方向性をはっきり決める場になる。

### 3.4.3 部費とショップ

本家はゲームモードの外でアイテムを買えるが、本作はモード内で完結させたいので
**部費という校内の予算**を設け、その範囲でショップを使う形にした。

#### 収入
| 収入源 | 金額 |
|---|---|
| 毎月の支給 | 8,000円 + 評判 × 400円（評判20で16,000円／評判100で48,000円） |
| 夏の地区大会 1勝ごと | 8,000円 |
| 秋季大会 1勝ごと | 6,000円 |
| 春の全国大会 1勝ごと | 60,000円 |
| 夏の全国大会 1勝ごと | 80,000円 |
| 地区大会 優勝 | +40,000円 |
| 春の全国大会 優勝 | +100,000円 |
| 夏の全国大会 優勝 | +150,000円 |
| 全国大会 出場（遠征補助） | 春 80,000円／夏 100,000円 |

勝つほど部費が増えるので、**評判と部費が同時に伸びる**。

全国大会の賞金だけ桁が違うのは、入場料の分配と寄付があるという理由づけ。
ゲーム上は **1勝ぶんの賞金が1泊ぶんの宿泊費を上回る**ようにしてある。
逆にすると「勝ち進むほど赤字」になり、勝ちたくないという歪んだ動機が生まれる。

#### 毎月の維持費（支出）
何もしなくても毎月出ていく固定費。**貯めるだけが常に正解**にならないようにするため。

| 項目 | 金額 |
|---|---|
| 備品費（ボール・バット・消耗品） | 部員1人あたり 400円／月 |
| 設備維持費 | (グラウンドLv − 1) × 6,000円／月（Lv1は0円） |

- 部員24人・Lv1なら 9,600円／月。部員40人・Lv5なら 40,000円／月。
- 支給は評判20で16,000円、評判100で48,000円なので、**規模が大きくなるほど手元に残らない**。
  月々の支給は「部の維持に消えるお金」、大会の賞金は「強化に使えるお金」という役割になる。
- これによってグラウンドの整備が**払い切りの強化ではなく、維持費を背負う決断**になる。
  整備ボタンには増える維持費を必ず表示する。
- 払いきれない場合は払える範囲だけ払い、道具が足りず**全員の信頼度が3下がる**。
  借金は作らない。
- ショップの「毎月の収支」で内訳と差引を確認できる。

#### 遠征費（支出）
遠くで試合するほど部費が出ていく。**所在地の選択に、回戦数とは別の軸**が入る。

| 場面 | 費用 |
|---|---|
| 地区大会 | 1試合ごとに 7,200円（県内の球場までの交通費） |
| 全国大会 | 会場までの往復（距離に比例）＋ 試合数ぶんの宿泊費（1泊 54,000円） |
| 練習試合の遠征 | 距離に応じて 6,480〜15,120円（日帰り） |

- 遠征は **18人ぶん**（ベンチ入りと引率）で計算する。
- 全国大会の会場は兵庫。**近畿の学校は宿泊費がかからない**（通いのため）。
- 距離は地方を「北から南へ」1本の軸に並べて測る（`AREA_POSITION`）。
  緯度経度を持たなくても、細長い日本ならこれで遠さの大小は再現できる。
  沖縄だけは必ず飛行機になるので、実距離より大きく離してある。
- 甲子園までの遠征費は所在地選択の画面に出す。神奈川で 91,800円、沖縄で 173,700円。

参加校が少なくて全国に出やすい地区ほど甲子園から遠い、という関係になっているので、
**「勝ち抜きやすいが遠征費が重い」「勝ち抜きにくいが近い」**のどちらを取るかを選べる。

#### 練習試合の遠征
練習試合マスの4割は他県への遠征になる（日帰りできる隣接地方まで）。

- 相手が格上（+8）になり、他県まで出向くこと自体が知名度になる（評判 +1）
- 部費が足りなければ招待を断り、地元開催に切り替える（借金は作らない）
- 沖縄は日帰り圏の地方が無いので、練習試合の遠征は起きない

#### アイテム（買った瞬間に効果が出る）
在庫や持ち物の管理は行わない。「買う→使う」の2手間はスマホでは煩雑なだけで、
判断の質が変わらないため。

| アイテム | 効果 | 価格 |
|---|---|---|
| スポーツドリンク | 全員の体力 +25 | 12,000円 |
| 高たんぱく弁当 | 全員の体力 +45 | 25,000円 |
| 練習器具一式 | 練習効率 1.5倍 × 5回 | 40,000円 |
| 最新トレーニング機器 | 練習効率 2倍 × 4回 | 80,000円 |
| 打ち上げの差し入れ | 全員のやる気 +1段階 | 30,000円 |
| メンタルコーチ招へい | 全員の信頼度 +12 | 35,000円 |
| 名将の指南書 | 信頼度が最も高い選手が特殊能力に挑戦 | 60,000円 |

### 3.4.4 グラウンドレベルとマネージャー

どちらも部費で買う**恒久的な強化**で、消耗品しか無かったショップに長期の使い道を与える。

#### グラウンド（Lv1〜99）
段階を細かくしたのは、部費の使い道を**終わらない**ものにするため。
5段階だと数年で上限に達し、以降は部費が余るだけだった。

| Lv | 呼び名 | 練習効率 | 次の1段階の費用 | 維持費/月 |
|---|---|---|---|---|
| 1 | 土のグラウンド | ×1.00 | 3,000円 | 0円 |
| 10 | 手入れされたグラウンド | ×1.18 | 30,000円 | 2,700円 |
| 25 | 整備された球場 | ×1.30 | 75,000円 | 7,200円 |
| 50 | 室内練習場つき | ×1.43 | 150,000円 | 14,700円 |
| 99 | 聖地と呼ばれる球場 | ×1.60 | — | 29,400円 |

- 練習効率は**平方根カーブ**。序盤ほど1段階の効きが大きい。
  直線にすると低い段階での整備がほとんど体感できない。
- 1段階の費用は `3,000円 × 現在のLv`。**Lv99まで上げると累計約1,450万円**かかる。
- ショップでは1段階ずつと10段階まとめての2通りを選べる。
- **毎月一定の確率で荒れて1〜2段階下がる**（Lv1で5%、Lv99で約30%）。
  維持費を払えなかった月は確率が2倍になる。
  これが無いと、部費が貯まった時点で最大段階に固定されてしまう。
- 「グラウンド整備」カードを使えば**部員総出で1段階上げられる**（無料）。
  何もしなくても Lv10 前後で荒れと釣り合うので、そこから先は部費を使う。

#### 練習器具（買うと練習の種類が増える）
アイテム（買った瞬間に効果が出る消耗品）と違い、器具は
**「選べる練習の種類が増える」**という形で効く。
ただし**一定の確率で壊れる**ので、買って終わりではなく維持の判断が続く。
恒久強化を上げっぱなしにできないようにする方針はグラウンドと同じ。

| 器具 | 使えるようになる練習 | 効果 | 価格 | 故障率 |
|---|---|---|---|---|
| ティースタンドとネット | ティー打撃 | ミート +8 | 60,000円 | 10%/月 |
| ラダーとミニハードル | アジリティ | 走力・守備 +5 | 80,000円 | 9%/月 |
| ベンチプレス一式 | ウエイト | パワー +7 / 肩力 +4 | 120,000円 | 5%/月 |
| ビデオ撮影機材 | ビデオ分析 | 変化球 +5 / ミート +4・**消耗なし** | 140,000円 | 8%/月 |
| ブルペン整備 | ブルペン投球 | コントロール・スタミナ +6 | 160,000円 | 6%/月 |
| ピッチングマシン | マシン打撃 | ミート・パワー +6 | 200,000円 | 12%/月 |

- 器具の練習は通常の練習より**1項目あたりの伸びが大きい**。それが買う理由になる。
- 壊れると持ち物から消え、**手札に残っていたそのカードも引き直される**
  （使えない練習が手札に残ると、選んでも何も起きないカードになるため）。
- 壊れたら同じ値段で買い直せる。
- 故障率は「酷使する器具ほど高い」で決めている。
  安い器具ほど壊れる、にすると「安物買い」の話になって選択が単純になる。

#### マネージャー（1人だけ雇える）
| 役職 | 効果 | 費用 |
|---|---|---|
| 記録係 | 練習の成長量 +8% | 180,000円 |
| トレーナー | 月替わりの体力回復 +15 | 180,000円 |
| 栄養士 | 練習の体力消費 -25% | 200,000円 |
| 分析担当 | 試合の守備力が上がる | 220,000円 |
| 主務 | 毎月の部費 +30% | 250,000円 |

### 3.4.5 コンバート

選手詳細のポジション適性をタップすると、その位置の適性を**1段階だけ**上げられる。

- 費用：15,000円 ＋ 体力 -15
- **上限は A**。S（本職）にはならない ＝ サブポジは本職を超えない
- 繰り返せば G → A まで上げられるが、そのぶん部費がかかる
- 本職と、すでにA到達済みの位置は選べない

### 3.4.6 日付固定イベント

毎年決まった月に必ず起きる学校行事。すごろくの乱数とは別に、**1年のリズム**を作る。

| 月 | 行事 | 効果 |
|---|---|---|
| 4月 | 入学式 | やる気 +1段階 |
| 6月 | 中間試験 | 体力 -8 |
| 8月 | 猛暑 | 体力 -10 |
| 9月 | 体育祭 | 信頼度 +6 |
| 11月 | 期末試験 | 体力 -8 |
| 1月 | 初詣 | やる気 +1段階 |
| 2月 | 体力測定 | 1人の体力 +20 |

**効果は控えめにしている。** プレイヤーが避けようのないイベントに大きなマイナスを置くと、
理不尽になるだけで判断の余地が生まれないため。

### 3.4.7 怪我と離脱

赤マスの結果のひとつとして怪我が起きる。**体力が低い選手ほど当たりやすい。**

- 離脱期間は1〜3ヶ月。月をまたぐごとに1つ減る
- 離脱中は**練習で伸びず、体力も減らない**（部活に出ていないため）
- 離脱中の選手は**スタメンから自動で外れる**（`repairLineup` が組み直す）
- 復帰時にログで知らせる

体力管理を怠ると主力を失うので、休養マスと休養カードの意味が一段強くなる。

### 3.4.8 急成長とスランプ

月ごとに、各選手へ偶発的な変動が起きる。実際の高校生が突然伸びたり崩れたりするのを再現する。

- **急成長**：2〜3の能力が +5〜13（発生率5%/月）
- **スランプ**：2〜3の能力が -4〜11（発生率5%/月）
- 下級生・やる気が高い・天才肌ほど**変動が大きい**（クールは振れにくい）
- 高い能力ほど急成長の伸び幅は小さくなる（90以上で1/4）
- 離脱中の選手には起きない

**上下をほぼ釣り合わせている。** 急成長だけが多いと「練習しなくても伸びる」ことになり、
練習の意味が薄れる。狙いは平均を押し上げることではなく、選手ごとの振れ幅を出すこと。

### 3.4.9 データ画面

各画面に散っていた「いまどうなっているか」を1か所に集める。
**ここは読むための場所**で、編成のような操作は各画面へ送る
（同じ操作を2か所に置くと、どちらが正なのか分からなくなる）。

| タブ | 内容 |
|---|---|
| チーム | 学校名・ユニフォーム・所在地・評判・部員数・ベンチ入り／ベンチ外・平均総合。編成画面への入口 |
| 成長 | 誰がどれだけ伸びたか（入学から／今年度／直近1ヶ月で切替。伸びの大きい順） |
| 設備 | 部費の収支（支給・維持費・差し引き）、グラウンドの段階、マネージャー、練習器具の所有状況 |
| 他校 | 県内10校と全国20校の戦力・対戦成績・注目選手・前年比 |
| 進路 | ドラフト指名（プロ入り）の一覧と、その他の進路。高校通算成績つき |
| スカウト | 今年度に視察した県と候補の一覧、前年度の結末 |
| 遊び方 | 各仕組みの説明12項目（アコーディオン。`ui/screens/helpTopics.ts`） |

**成長タブは状態を持たない。** `Player.history`（月ごとの能力の記録）から
差を取るだけで、判定には一切使わない（`core/player/growthReport.ts`）。

**遊び方タブは機能を足したら必ず更新する。** 守備適性の重みや評判の効き方のように、
触っただけでは分からない仕組みが多い。数値を書くときは定義側の定数と突き合わせること。

### 3.5 世代交代
**3月の月末に「次の月へ進む」と、その場で1年が切り替わる。**

1. 3年生が全員卒業する（OB名鑑に記録が残る）
2. 残った選手が1学年ずつ進級する
3. 新入生が加入する（人数・実力は学校の評判で決まる）
4. 崩れたスタメンは自動で組み直される

専用の報告画面（`SeasonScreen`）で卒業生と新入生を一覧表示し、
「新年度を始める」を押すまで他の画面へは移動できない。

#### 新年度に学校を変えられる
年度の切り替わり（世代交代の画面）でだけ、**学校名・ユニフォーム・所在地**を変えられる。
何も触らなければ変更なしで進む。

- ユニフォームは6色から選ぶ。**学校名から色を導かない。**
  導いていた頃は、学校名を変えると色まで変わってしまい、選ぶこともできなかった。
- 所在地を変えると大会の回戦数・遠征費・県内のライバル校が入れ替わる。
  **県外の全国クラスの学校はそのまま残す**（甲子園で当たってきた相手を消すと、
  対戦成績が意味を失うため）。

#### ゲーム開始時も新入生の入学から始まる
**新規開始は4月なので、まず新入生の入部から始まる。**
最初から3学年そろっているより、自分の代を迎え入れるところから始まるほうが自然なため。

- 初期部員として作るのは2・3年生だけ（各8人）。
- 1年生は**世代交代と同じ `recruitFreshmen()`** で入部させる。
  人数と実力は学校の評判（初期値20）で決まり、経路が1本なので挙動がずれない。
- 開始直後の画面は `SeasonScreen`（1年目 春）。卒業生は空、新入生だけが並ぶ。

#### 学校の評判（0〜100 / G〜S）
能力値と同じ **G〜S の8段階**で表す。星1〜5では段階が粗く、
評判を上げた手応えが出にくかった。能力と同じ表記に揃えると
「うちはまだ D の学校」のようにチームの位置づけを同じ感覚で読める。

| グレード | 評判 | 呼び名 | 手札 |
|---|---|---|---|
| G | 0〜11 | 無名校 | 4枚 |
| F | 12〜23 | 弱小校 | 4枚 |
| E | 24〜35 | 中堅以下 | 5枚 |
| D | 36〜49 | 中堅校 | 5枚 |
| C | 50〜63 | 有力校 | 6枚 |
| B | 64〜77 | 強豪校 | 6枚 |
| A | 78〜89 | 名門校 | 7枚 |
| S | 90〜100 | 全国屈指 | 8枚 |

**評判が上がると手札が増える**。能力を直接盛るより、
プレイヤーの判断の幅が広がるほうが報酬として面白いため。

#### 学校の評判の詳細
- 初期値は **20**。
- 評判が高いほど**新入生の実力が上がり、人数も増える**（4〜16人）。
- 評判55以上で、まれに **推薦の逸材**（大幅に強い新入生）が入部する。
- **評判20を実力補正0の基準にしている。** ここをずらすと、何もしなくても
  新入生が毎年弱くなりチームが衰退する（実際に一度そうなった。docs/balance.md 参照）。

#### 評判は「誰に勝ったか」で動く
勝てば +1、負ければ -1 の固定だった頃は、**誰と戦ったかが評判に関係しなかった**ので、
弱い相手を選んで勝ち続けるのがいちばん効率の良い立ち回りになっていた。

相手にも自校と同じ物差しの評価を持たせ、**力の差で振れ幅を変える**
（`core/season/matchReputation.ts`）。

```
自校の評価 = スタメン9人の平均総合
相手の評価 = 37 + 相手の強さ（0が互角）
```

| 結果 | 増減 |
|---|---|
| 互角に勝つ | +1.0 |
| 格上（+20）に勝つ | **+5.0** |
| 格下（-20）に勝つ | +1.0 |
| 互角に負ける | -0.4 |
| 格上（+20）に負ける | -0.2 |
| 格下（-20）に負ける | **-5.4** |

- 勝ちの基本値より**負けの基本値を小さく**してある。1.0にしていたら、
  年に十数試合ある練習試合と大会で負けが込むたびに削られ、
  長期プレイで評判が一桁まで落ちて回らなくなった（実測で60年後に7）。
- 力の差は**試合前のスタメン確認に「格上」「互角」などと表示**される。
  勝ったときにどれだけ動くかが、試合を始める前に読める。
- 大会の試合もこれで動く。決勝で勝つことと1回戦で勝つことが同じ重みにならない。

#### 評判は上でも下でも鈍る
```
上がるとき … × (1 - 評判/100)^2   評判20で90% / 50で60% / 80で26% / 95で9%
下がるとき … × max(0.25, 評判/100) 評判20で25% / 50で50% / 100で100%
```
上に行くほど上がりにくいのは、1年目で100に張り付くのを防ぐため。
**下に行くほど下がりにくいのは、落ちきると立て直せないため。**
負けるたびに削られる仕組みを入れたら、勝てないチームの評判が
一桁まで落ちて新入生も部費も枯れた。無戦略プレイでも20前後で底を打つ。

#### 卒業後の進路（OB名鑑）
**卒業した選手は消えず、在学中の選手と並行して毎年その後が進む。**

卒業時の総合と学校の評判で進路が決まる。

| 進路 | 条件（総合の目安） | その後 |
|---|---|---|
| プロ入り | 82以上 | 毎年の成績が積み上がる |
| 大学進学 | 62以上 | 4年後の到達点でプロ／社会人／引退に分かれる |
| 社会人 | 46以上 | 数年でプレーを終える |
| 競技引退 | それ未満 | — |

#### プロ入りで能力はプロの物差しに置き換わる
高校の総合はあくまで**高校生の中での物差し**。そのまま持ち込むと、
卒業した年から一線級の成績を残してしまい、
「プロで通用するか」という段階が消えていた。

| | 割合 | 倍率 |
|---|---|---|
| ほとんどの選手 | 85% | **×0.5** |
| プロの水に合う | 12% | ×0.7 |
| 別格 | 3% | ×0.85 |

総合90でプロ入りしても、ふつうは45から始まる。
**プロ入り後の能力（おおむね20〜60）は高校の基準と混ぜて読まないこと。**
戦力外は22未満、海外挑戦は62以上が目安。

**プロ入り後**は毎年の成績（打率・本塁打・打点／勝敗・防御率・奪三振）が記録される。
- 5年目までは伸び、その後は下降する
- 実力が落ちきると**戦力外**。社会人で続けるか引退する
- 実力が飛び抜けていて若ければ**海外リーグへ移籍**することがある
- 12年以上でいずれ引退する

#### OB名鑑に載るのはプロだけ
卒業生を全員並べていた頃は、高校で競技を終えた選手や社会人へ進んだ選手で埋まり、
**「うちからプロが出た」という出来事が名鑑の中に埋もれていた**。

- OB名鑑（部員一覧から開く）に載るのは**プロへ届いた選手だけ**。
- **大学に進んだ選手は在学中ここに出ない。** 4年後に指名されて初めて名前が現れる。
- それ以外の卒業生は「データ → 進路」で追う
  （プロ入り／プロを目指している／競技を終えた の3つに分かれる）。
- 名鑑では通算成績・年度別成績に加えて、**プロでの実力の推移をグラフ**で見られる。
- 記録の保持上限（60人）で切るときも、**プロに届いた選手は落とさない**。
  単純に新しい順で切ると、何年も経ったあとに古いプロOBが名鑑から消える。

### 3.6 歴代記録

在校生と卒業生を**同じ土俵に並べて**、学校の歴史として残す
（部員一覧 →「歴代記録」）。通算成績は積み上がっても、
卒業した瞬間に見えなくなるのでは積み上げる意味が薄いため。

- **歴代ベストナイン** … ポジションごとに1人。**本職の位置でだけ競わせる**
  （守れる位置すべてで候補にすると、打てる選手が9枠を独占して「ナイン」にならない）。
  5試合以上の出場が条件（1試合だけの打率10割で1位にならないように）。
  野手は OPS と出場数、投手は投球回と防御率で決める。
- **通算記録** … 本塁打／安打／打点／盗塁／打率／OPS／勝利／奪三振／防御率／奪三振率。
  率の部門だけ規定打席（50打数）・規定投球回（30回）に相当する下限を置く。

### 3.6.1 個人の通算成績

**高校3年間の成績が積み上がっていく。** 選手データの「成績」タブで見られる。

| 野手 | 試合 / 打席 / 打率 / 安打 / 本塁打 / 打点 / 盗塁 / 出塁率 / OPS |
|---|---|
| **投手** | 登板 / 投球回 / 勝敗 / 奪三振 / 防御率 / 奪三振率 |

- 保存するのは**素の数だけ**。率は表示のたびに計算する
  （率を保存すると試合を足したときに合成できず必ず狂う）。
- 自責点は失策がからんだ得点を除く。
- 勝敗は**最も長く投げた投手**に付ける（本来の規定は複雑なため）。
- 出場していない試合は試合数にも数えない。

#### 試合の成績による能力の変動
練習だけで伸びると、試合が「結果を見るだけ」の場面になってしまう。
打った・抑えた選手は**その場で伸び、打てなかった選手は落ちる**。

**引き金は勝敗ではなく、その選手自身の成績。** 勝った試合に上乗せしていた頃は、
4タコでも勝ちチームに居れば伸び、好投しても味方が打てなければ損をした。
チームの勝敗はその選手の出来ではないので、評価に混ぜない。

| 打撃 | 点 | | 投球 | 点 |
|---|---|---|---|---|
| 安打 | +1.0 | | アウト | +0.25 |
| 長打（二・三塁打） | +1.0 | | 奪三振 | +0.5 |
| 本塁打 | +2.0 | | 自責点 | **-0.8** |
| 打点 | +0.6 | | 被安打 | **-0.15** |
| 盗塁 | +0.8 | | 与四球 | **-0.2** |
| 四球 | +0.3 | | | |
| 凡打（打数−安打） | **-0.35** | | | |
| 三振 | **-0.25** | | | |

- 3点で1段階動く。4打数0安打2三振ならはっきりマイナスになる。
- **落ち幅は伸び幅の55%、1試合で最大2段階まで。** 1試合の不振で積み上げが崩れると、
  主力を試合に出すこと自体が怖くなる。
- 変動する能力は内容に寄せる（投げて抑えたなら投手能力、走ったなら走力）。
- **負ければ終わりの大会は得るものが大きい**（地区大会 1.5倍・全国大会 2倍）。
  1試合の上限も練習試合3段階／地区4段階／全国5段階と広がる。
  これは勝敗ではなく舞台の格なので、成績を引き金にする方針と矛盾しない。

#### 大会を戦い抜いたことによる成長
1試合ごとの成長とは別に、**大会が終わった時点で**勝ち上がった深さに応じて
チーム全体が伸びる（`core/tournament/tournamentGrowth.ts`）。
練習試合を10回こなすより、県大会を勝ち上がった1週間のほうが選手は変わる、という考え方。

```
経験点 = (勝ち数 + 0.5 + 優勝なら2) × 大会の格
大会の格：夏の地区 1.0 ／ 秋季 0.9 ／ 春の全国 1.4 ／ 夏の全国 1.6
```

- **1勝もできなければ0。** 出ただけで伸びるなら「結果で伸びる」という筋が通らない。
- 伸びるのは**その大会を戦ったメンバー**（スタメンと、その半分でベンチ入り）。
  ベンチ外と離脱中の選手は対象外。
- 大会は総合力を問われる場なので、練習と違って**能力を選ばず幅広く**伸びる。
- 誰が何試合出たかは持たない。大会が終わった時点の編成で近似する
  （試合ごとの出場記録を持ち回るとセーブが膨らむ）。

#### 大会で身につく特殊能力
経験点に応じて、出場メンバーが特殊能力を習得することがある（1点あたり2%、上限35%）。

- 特訓マスに止まるのを待つしかなかった習得経路に、**「勝てば付く」という道**を足した。
- **金特に手が届くのは優勝したチームだけ**で、そのうち信頼度60以上の選手のみ。
  特訓と同じ基準に揃えてある。
- 赤（マイナス能力）が付くことはない。

### 3.7 ライバル校

対戦相手をその場で作って捨てていたので、**自分だけが強くなり、
周りは何年経っても同じ**という世界になっていた。30校を保存し、毎年動かす。

| | 校数 | 役割 |
|---|---|---|
| 県内 | 10 | 夏・秋の地区大会と、地元の練習試合の相手 |
| 県外 | 20 | 全国大会の相手。U18の選考基準もこの顔ぶれで決まる |

- 各校は変わらない**地力**と、毎年揺れる**戦力**を持つ。戦力は地力へ引き戻される
  （引き戻さないと強豪が際限なく強くなる）。
- 県外の20校は**1県に1校まで**で全国に散らし、地力は県内より高くしてある
  （県大会を勝ち抜いてきた顔ぶれなので）。全国大会では相手の代表県も表示する。
- 遠征の練習試合も、**行き先の県に学校があればそこから相手を引く**。
  遠征先は学校を置いてある県を優先して選ぶ（縁のある相手と何度も当たるほうが、
  毎回知らない名前が出るより遠征に意味が出る）。
- **学校ごとに対戦成績を残す。** 試合前の確認画面に
  「通算2勝3敗／前回：1年目 神奈川 夏の大会 準決勝で敗戦」のように出る。
  勝ち上がりに物語が乗るようにするための記録で、判定には一切使わない。
- 各校が**注目選手**を2人ずつ抱える。学年が上がるごとに伸び、3年で卒業して入れ替わる。
- **回戦ごとの難易度の曲線は変えず**、それに近い戦力の学校を当てる。
- はっきり戦力が動いた学校は世代交代の画面で報告する（「○○が力をつけてきた」）。

### 3.8 新入生のスカウト

**まず行き先の県を選ぶ。** 出張費は距離で決まるので、
弱小校は地元近辺しかまわれない。勝って部費が増えると遠くの県へ足を伸ばせる。

```
県を選ぶ（出張費を払う）
  → その県の候補10人が挙がる（中学の成績つき）
  → 1人に会いに行く（＝この出張を使い切る）
  → もう1人会いたければ、もう一度出張する
```

- 解禁は**10月**。年度が替わるまで通える。
- **候補は県を選んだ時点で生成される。** 生成しておかないと
  「他校へ行った」という結末が作れない。
- 候補はその年度のあいだ残るので、**同じ県へ通い直せる**。1人につき最大4回。
- 会いに行った回数がそのまま入部の見込みになる。

#### 県ごとの傾向
出張費を払う前に**行き先を選ぶ材料**が要る。名前だけ並んでいても、
遠い県へ行く理由が生まれない。県ごとに「どんな選手が多いか」を持たせている。

| 傾向 | 内容 |
|---|---|
| 長距離砲の産地 / 打撃巧者が多い / 俊足が多い | 対応する能力が高い選手が多い |
| 守備が堅い | 守備・捕球の水準が高い |
| 投手王国 | 投手の比率が上がり、球速も出る |
| 粗削りな素材型 | 完成度は低いが素質が高い |

傾向は**候補の生成にも実際に効く**。表示だけの飾りにすると、
「投手王国と書いてあるのに投手が居ない」が起きて信用されなくなる。
**傾向は毎年引き直され、必ず前年と違うものになる。**
固定にしていた頃は、一度「投手王国」を見つけたら毎年そこへ行くだけになり、
行き先を選ぶ判断が1年目で終わっていた。
その学年にどんな中学生が育ったかは年ごとに違う。

#### 出張費（神奈川から）

| 行き先 | 神奈川 | 静岡 | 大阪 | 広島 | 福岡 | 沖縄 |
|---|---|---|---|---|---|---|
| 出張費 | 8,000円 | 13,400円 | 18,800円 | 26,000円 | 42,200円 | 62,000円 |

月の部費は評判20で16,000円、評判95で46,000円。
**弱小校のうちは地元近辺を1〜2回まわるのが精一杯**になる。

#### 候補の見え方
総合値だけでは「どういう選手か」が伝わらないので、**中学での成績**を出す。

- 所属（○○中学校 / ○○ボーイズ）と最高到達点（全国大会ベスト8 など）
- 野手なら打率と本塁打、投手なら防御率と最速
- 触れ込みの**特殊能力**（赤特は付かない）。獲れば入学時から持っている

判定に使うのは素質（総合）だけで、中学の成績は表示のためのもの。

#### 結末
- 会いに行った候補は成否が出る。獲れれば1年生として入部する。
- **会いに行かなかった候補も進学先が決まる。** 「あのとき通っていれば」が後から分かる。
- 逃した選手のうち素質50以上は、その県の学校の注目選手として残る
  （全員を抱えさせるとセーブが膨らむため）。
- 世代交代の画面には**会いに行った候補だけ**を出す。
  視察した県の全員（10人×県数）を並べると読み切れないので、
  残りは「データ」画面で確認する。

### 3.9 U18日本代表

**冬前（11月）に、他校と比べて抜けている選手が召集される。**

- 条件は総合75以上かつ2年生以上で、さらに**全国の当落線を上回っている**こと。
  全国の注目選手（上級生）を強い順に並べ、代表枠18人目にあたる選手が基準になる。
  相対評価なので、弱小校のうちはまず選ばれない。
- **「県内でいちばん強い1人」と比べてはいけない。** 比較対象が1人だと、
  その選手が卒業した年だけ基準が急に下がる。さらに参加校の多い県ほど強い選手がいるので、
  **地区選択の難易度差がそのまま選考の厳しさに乗ってしまう**。
- 1校から選ばれるのは最大2人。
- 大会での活躍度は実力しだい。活躍すれば能力が伸び、
  **卒業時のドラフト指名の確率が大きく上がる**（`decidePath` に加算される）。
- 実測（6シードの平均・代表経験者の人数）:
  1年後 0.0人 ／ 2年後 1.0人 ／ 3年後 2.2人 ／ 6年後 2.0人。

## 4. 技術スタック

| 領域 | 採用 | 理由 |
|---|---|---|
| 言語 | TypeScript (strict) | ロジックが複雑なため型安全は必須 |
| ビルド | Vite | 高速HMR、PWA対応が容易 |
| UI | React 19 | 画面遷移・リスト・フォームが多いUI主体のゲーム |
| 状態管理 | Zustand | 単一ストア＋薄いAPI。セーブデータとの相性が良い |
| 描画 | SVG + CSS のみ | Pixi.js は採用しなかった（約400KBあり、バンドル全体の4倍。SVGで十分だった） |
| テスト | Vitest | ゲームロジック（純関数）のユニットテスト |
| 保存 | localStorage + JSONスキーマ版管理 | オフライン動作。将来のクラウド同期も見据える |
| Lint | oxlint | Vite 8 テンプレート標準。高速 |

### セーブの枠
**3つの枠**を持つ。1枠しか無かった頃は、別の学校で試したくなるたびに
それまでの記録を消すしかなかった。歴代記録やOB名鑑のように何年もかけて
積み上がるものがあるので、消すのは重い判断になる。

- タイトル画面で枠を選ぶ。中身があれば続きから、空なら新規作成へ。
- **1枠目のキーは1スロットだった頃と同じまま**（`hs-baseball-sim:save:v1`）。
  変えると既存のセーブが読めなくなる。
- 削除は枠ごとに、必ず一度確認を挟む。

### 公開（無料の静的ホスティング）

ビルド結果は**ただの静的ファイル**（HTML/JS/CSS）なので、サーバー側の処理は要らない。
スマホから遊ぶには、どこかに置いて HTTPS で配信すればよい。

**GitHub Pages を既定にしている。** 公開リポジトリなら Pages も Actions も無料枠で足り、
push するだけで自動的に差し替わるため。`.github/workflows/deploy.yml` が
型チェック・Lint・テストを通してからビルドし、公開する。

```bash
git init && git add -A && git commit -m "初回"
gh repo create hs-baseball-sim --public --source=. --push
# GitHub の Settings → Pages → Source を「GitHub Actions」にする
```

公開先は `https://<ユーザー名>.github.io/<リポジトリ名>/`。

- **サブパス配信に対応している。** `vite.config.ts` の `base` を
  環境変数 `BASE_PATH` で切り替え、ワークフローがリポジトリ名を渡す。
- manifest と Service Worker のパスは**すべて相対**にしてあるので、
  ルート配信（Cloudflare Pages / Netlify）でもそのまま動く。
  その場合は `npm run build` の結果（`dist/`）をアップロードするだけでよい。

```bash
# ルート配信のホストへ手で上げる場合
npm run build   # BASE_PATH は指定しない
```

### PWA
`public/manifest.webmanifest` と `public/sw.js` で、**ホーム画面に追加してオフラインで遊べる**。

- Service Worker はビルドのファイル名ハッシュに依存しない作りにしている
  （事前に一覧を焼き込まず、取得したものを都度キャッシュする stale-while-revalidate）。
  これによりビルド構成が変わっても壊れない。
- 画面遷移だけはネットワーク優先で、オフライン時にキャッシュした `index.html` を返す。
- 開発中（`npm run dev`）は登録しない。HMR と衝突するため。
- アイコンも SVG（通常用とマスク用の2種）。

### サウンド
**音声ファイルを持たず、Web Audio API でその場で合成する。**
画像を使わない方針と同じ理由で、アセットを増やさずオフラインでも鳴る。

- 効果音：カード選択／安打／本塁打／アウト／歓声／習得音
- ブラウザの自動再生制限があるため、`AudioContext` は**最初のタップまで作らない**
- ヘッダーの 🔊 で切り替え。設定は端末（localStorage）に保存され、セーブデータとは分ける

### 選手の顔
選手ごとに**顔をその場で生成**する（`PlayerPortrait`）。
肌の色・陰影・髪型・髪色・眉・目の大きさ・輪郭・口の形をパーツ化し、
選手idのハッシュから組み合わせる。同じ選手はいつでも同じ顔になる。

> **写真調にはしていない。** 実写を出すには写真素材を同梱するか
> 実行時に画像生成モデルを呼ぶ必要があり、どちらも
> 「アセットを持たずオフラインで動く」という本作の前提と両立しない。
> ベクターで陰影を付けた肖像を、実現可能な範囲での最大限としている。

### ビジュアル方針
**画像ファイルを一切使わず、絵はすべて SVG と CSS で描く。**
グラウンドの情景・選手のスプライト・カードの絵柄・アイコンまで全部コードで生成する。

- 通信なしで動く（PWA・オフライン対応が容易）
- 季節やチームカラーの変更が CSS 変数の差し替えだけで済む
- 画像の管理・圧縮・解像度対応が不要で、バンドルも軽い（現状 gzip 約 103KB）

なお、本作は市販タイトルの**画面構成**（情景を常時表示する／カードを絵で見せる等）を参考にしているが、
アセット・キャラクターデザイン・ロゴは一切模倣せず、すべて独自に描き起こしている。

### アーキテクチャ原則
**「ゲームロジック（`src/core`）は React にも DOM にも一切依存しない純粋な TypeScript」** を最重要ルールとします。

```
  UI層 (React)  ──dispatch──▶  ゲームエンジン (純粋関数)
       ▲                              │
       └──────── 新しい GameState ────┘
```

- `core` は「現在の状態 ＋ プレイヤーの入力」を受け取り「新しい状態 ＋ 発生イベントのログ」を返すだけ。
- 乱数は **シード付きPRNG** を `core` 内で持ち回る。`Math.random()` の直接使用は禁止 → リプレイ・デバッグ・テストが可能になる。
- これにより、UIをPixi.jsやネイティブに差し替えてもロジックを再利用できる。

## 6. MVP（フェーズ1）のスコープ

**ゴール：「カードを1枚選ぶ → マスを進む → 能力値が上がる」が1ヶ月ぶん動く。**

含むもの：
- 部員10人の自動生成（能力ランダム）
- 手札5枚の抽選とカード選択UI
- マス移動と、練習マス／良イベント／悪イベントの解決
- 能力値の上昇と、その差分表示（`ミート 32 → 35 (+3)`）
- 部員一覧・選手詳細画面
- localStorage への自動セーブ／ロード
- 縦画面レイアウト（片手操作・下部固定ナビ）

**含まないもの**：現時点で予定している機能は一通り実装済み。

### 実装済みの機能

- 部員24人（各学年8人、学年ごとに投手を1人確保）の自動生成
- 手札5枚の抽選 → カード選択 → コマ移動 → マス解決 → 1枚補充
- 練習9種・**マス11種**・成長計算（やる気／学年／体力／カンスト補正）
- **練習効率バフ**（黄マス → 練習マスで消費）
- **特殊能力**（金/青/赤 17種）と**特訓マス**での習得
- **ポジション適性**（全9ポジション S〜G）と**スタメン編成**（自動編成・検証・修復）
- **試合シミュレーション**（完全自動・観戦速度3段階・結果サマリー・投手交代）
- **世代交代**（卒業・進級・新入生加入・OB名鑑）と**学校の評判**
- **相手の格で動く評判**（格上を倒せば大きく上がり、格下に負ければ大きく下がる）
- **プロ入りで能力がプロの物差しに置き換わる**（多くは半減。稀に適応する選手も）
- **OB名鑑はプロ入りした選手だけ**（大学経由の指名もここに現れる。実力の推移をグラフ表示）
- **レア性格「天才肌」**（出現率2%。初期能力も成長も別格）
- **毎年変わる県ごとのスカウト傾向**
- **大会**（地区ごとに異なる回戦数・夏/春の全国大会・タイブレーク）と**所在地の選択**
- **回戦ごとの大会マス**（1回戦・2回戦…が別のマスに並び、間は普通に練習できる）
- **3年生の夏引退**（夏の大会を最後にチームを離れ、秋は新チームで戦う）
- **冬合宿**（12月に強化方針を1つ選ぶ）
- **部費とショップ**（毎月の支給＋大会の賞金でアイテムを購入）
- **グラウンドLv1〜99**（整備で上がり、放っておくと荒れて下がる）
- **練習器具**（買うと練習カードの種類が増える。確率で壊れる）
- **評判のG〜Sグレード**（上がると手札が5〜8枚に増える）
- **24種類のカード**（練習に加えて運営に効くカードと、器具で解放されるカード）
- **遠征費**（全国大会・地区大会・練習試合の遠征。所在地が遠いほど重い）
- **毎月の維持費**（設備と備品。部員が増え、設備を良くするほど高い）
- **選手ごとの練習方針**（能力を指定して重点強化／コンバート）
- **コンバート**（練習を重ねてポジション適性を上げる。Aが上限）
- **マネージャー**（5種・1人在籍）
- **性格の効果**（6種。成長と試合の両方に影響）
- **個人の通算成績**（打率・OPS・防御率・奪三振率などが3年間積み上がる）
- **試合の成績による能力の変動**（打てば伸び、打てなければ落ちる。勝敗は関係しない）
- **大会を戦い抜いたことによる成長**（勝ち上がるほどチームが伸び、特殊能力も身につく）
- **盗塁**（走力と捕手の肩で成否が決まる）
- **代打と継投の自動判断／観戦中の手動交代**
- **ライバル校**（県内10校。毎年戦力が動き、注目選手が育つ）
- **新入生のスカウト**（評判で成功率、部費で費用。逃した選手の進学先も分かる）
- **U18日本代表**（冬前に相対評価で召集。活躍するとドラフト指名率が上がる）
- **日付固定イベント**（毎年決まった月の学校行事7種）
- **ルート分岐マス**（3つの道筋からこの先のマスの傾向を選ぶ）
- **怪我と離脱**（赤マスで発生。離脱中は練習もスタメンも外れる）
- **試合のダイヤモンド表示**（走者・アウト・打球・得点フラッシュ）
- **効果音**（Web Audioで合成。ヘッダーで切り替え）
- **PWA**（ホーム画面に追加してオフラインで遊べる）
- **卒業後の進路シミュレーション**（プロ／大学／社会人・年度別成績・戦力外・渡米）
- **急成長とスランプ**（月ごとの偶発的な能力変動）
- **24〜40人規模の部員**と**ベンチ入り／ベンチ外**
- **選手ごとに生成される顔**（`PlayerPortrait`）
- **伸びやすい能力の個人差**（得意2つ・苦手2つ。練習の結果が選手ごとに違う）
- **練習・試合の結果を選手ごとに表示**（誰がどの能力を伸ばしたかが名前で分かる）
- 部員一覧・スタメンで**各能力のランクを常時表示**
- **ポジションで色分けしたネームプレート**（本職＋他に守れる位置が色で混ざる）
- **⠿ をつまんでスタメン／ベンチ入り／ベンチ外を入れ替え**（つまみ以外の場所は普通にスクロールできる）
- **おまかせ編成3方針**（バランス／能力優先／若手優先）
- **成長タブ**（入学から／今年度／直近1ヶ月で、誰がどれだけ伸びたかを一覧）
- **遊び方タブ**（12項目の仕組み解説をアコーディオンで表示）
- **試合前のスタメン確認**（組み替えた編成が結果に反映される）
- **選手データ画面**（能力／特殊能力／成長／起用の4タブ。投手能力を詳細に表示）
- **データ画面7タブ**（チーム／成長／設備／他校／進路／スカウト／遊び方）
- **能力の推移グラフ**（入学時からの記録を項目ごとの折れ線で表示）
- **新規開始は新入生の入学から**（評判に応じた人数が4月に入部する）
- **1マス1日・1年365マスの盤面**（月ごとのゴールは無い。大会と合宿は日付のマスで強制ストップ）
- **地名ベースの他校名**（全49県の実在地名から生成。約75%が地元の地名）
- localStorage への自動セーブ／復元（3枠＋バックアップ＋v1〜v26 の移行を実装済み）
- 12画面（タイトル／新規作成／ホーム／スタメン確認／試合／大会／合宿／世代交代／スタメン／部員一覧／選手詳細／ショップ）
- SVG/CSS のみで描くグラウンド情景・選手スプライト・絵入りカード（季節で変化）
- テスト664件
